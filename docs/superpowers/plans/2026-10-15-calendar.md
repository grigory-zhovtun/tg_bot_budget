# Календарь записей во вкладке «Прогноз» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Траты можно запланировать на дни внутри статей плана — разово, каждый день, по дням недели или раз в месяц. Записи лежат на листе «Календарь», резервируются в своей статье, закрываются фактом и сразу видны во вкладке «Прогноз» (сетка месяца, карточка дня, список «Записи», окно записи) и в карточке «💳 Сумы».

**Architecture:** Новый чистый модуль `app/services/calendar.py` разбирает строки листа, раскладывает записи на вхождения в дни и закрывает их операциями `fact` — на утро (для резерва статьи) и на сейчас (для событий линий). `app/services/forecast.py` резервирует записи в статьях, ставит открытое в их дни и отдаёт статьи, список записей и подсказки сумм. `GoogleSheetsService` читает лист с копией на 60 секунд и пишет строку A:J по ID значениями как есть. API: записи в `GET /api/forecast`, `POST /api/calendar`, `PUT` и `DELETE /api/calendar/{id}` — каждый отвечает свежим прогнозом и шлёт заметку второму пользователю. В приложении сетка месяца заменяет ленту недели; в карточке дня — записи и «＋ Запланировать», ниже графика — список «Записи», окно записи снизу.

**Tech Stack:** Python 3.12, Starlette, Pydantic 2, gspread 6.1, pandas; React 19.3, TypeScript 6.0 (strict, `noUncheckedIndexedAccess`), Vite 8.3, Tailwind 4.3, Vitest 5.0, Testing Library.

- Лист «Календарь» (спека 3, 5.4): шапка `ID | Дата | Повтор | Дни | Группа | Подкатегория | Валюта | Сумма | Название | Кто`; строка A:J пишется значениями как есть (RAW): дата — текст «ДД.ММ.ГГГГ», повтор — `нет`, `каждый день`, `по дням недели`, `раз в месяц`, дни — `пн вт ср чт пт сб вс` через пробел, сумма — числом; ID — 6 символов `a–z0–9`, первый — буква. Листа нет — записей нет, первая запись создаёт лист с шапкой. Копия листа живёт 60 секунд, запись ботом её сбрасывает. Правка и удаление — по ID в колонке A; строки нет — `404`.
- Разбор листа: дата — серийное число или «ДД.ММ.ГГГГ», повтор — без учёта регистра, валюта — в верхний регистр. Строка без ID, даты, группы, подкатегории, валюты или суммы больше нуля, с незнакомым повтором или днём недели, без дней у «по дням недели» пропускается с `logger.warning`; остальные записи считаются.
- Вхождения (спека 4.1): `нет` — дата записи; `каждый день` — каждый день с даты; `по дням недели` — эти дни недели с даты; `раз в месяц` — число даты, в коротком месяце — его последний день.
- Закрытие (4.2): операции — `expenses()` с суммой больше нуля. Разовую запись с датой с `сегодня − 14` закрывает одна операция той же статьи (подкатегория + валюта) на сумму записи ±10 % с даты − 3 дня по дату (на утро — не позже вчера, на сейчас — не позже сегодня); записи берутся по порядку дат, операция закрывает одну запись, из кандидатов — ближайшая по сумме, потом по дате; операции, закрывшие платежи списка, не берутся; закрытое к утру остаётся закрытым и на сейчас. Сегодня траты статьи (без этих операций) засчитываются в её сегодняшние вхождения: `f = min(траты / Σ вхождений; 1)`, остаток `сумма × (1 − f)`, при `f ≥ 0,9` вхождения закрыты.
- Резерв (4.3): `остаток = max(план − факт с 1-го по вчера; 0)`, `записи` — Σ открытого на утро с сегодня по конец месяца; по дням раскладывается `Σ (остаток − min(записи; остаток))` минус неоплаченные платежи списка (правило переноса между валютами — как в прогнозе); `записи > остаток + 0,01` — у записей статьи «сверх плана»; статья без строки во вкладке — план 0.
- Линии (4.4–4.5): «по плану» — открытое на сейчас у всех вхождений в их день, «потрачено сегодня» — без засчитанного во вхождения; «по темпу» — только разовые записи; из окна темпа исключаются операции, закрывшие разовые записи к утру; траты сегодня для темпа — без засчитанного только в разовые.
- Подсказки (4.7): «обычно» — медиана операций статьи за 90 дней до сегодня, «в прошлый раз» — последняя, «в среднем в день» — сумма за 30 дней / 30; сумы — до тысячи, остальное — до целых; ключ `подкатегория|валюта`.
- Карточка «💳 Сумы» (4.6): `day_budget` получает записи календаря — утреннее сообщение, `/today`, «Сводка» и советник называют тот же день, что прогноз.
- API (спека 5): `GET /api/forecast` дополняется `currencies[].records`, `rates`, `calendar`, `articles`, `hints`; `POST /api/calendar`, `PUT /api/calendar/{id}`, `DELETE /api/calendar/{id}` отвечают свежим прогнозом. `422 validation` с полями: `date` «Дата — не раньше сегодня и не дальше чем через год» (у правки повтора прежняя дата из прошлого остаётся), `amount` «Сумма — больше нуля, до двух знаков после запятой», `group` «Такой статьи нет — обновите приложение» (нет в справочнике, «💰 ДОХОДЫ» или «💳 СЧЕТА»), `subcategory` «Такой подкатегории нет — обновите приложение» (как у траты), `currency` «Такой валюты нет у карт», `weekdays` «Выберите дни недели», `name` «Название — до 60 символов», `repeat` «Такого повтора нет — обновите приложение»; `404 record_not_found` «Запись уже удалили — обновите прогноз»; `503 sheets_unavailable` «Таблица не ответила — попробуйте ещё раз». Повтор `POST` с тем же `entry_id` строку не пишет.
- Заметка второму пользователю — без рода, как у плана: «📅 Иван — новая запись: 17.10 Детский центр 320 000 UZS (ДЕТИ / развитие)», «📅 Иван — запись изменена: …», «📅 Иван — запись удалена: …»; без имени — «📅 Новая запись: …»; у повтора вместо даты — «каждый день с 15.10», «пн ср с 20.10», «15-го каждого месяца».

## Review Focus

1. **Двойное нажатие «Запланировать» на медленной сети** — на листе одна строка: сервер не пишет повтор с тем же `entry_id`, окно шлёт один запрос (тесты в Task 5 и Task 8).

```python
from collections.abc import Sequence
from datetime import date
from typing import Any

import pytest

from app.domain import Rates
from app.services.analytics_service import transactions_frame
from app.services.calendar import (
    HEADER,
    CalendarRecord,
    CalendarState,

    hints,
    new_id,

    read_calendar,
    record_row,

from tests.test_analytics_service import serial
from tests.test_day_budget import FACT_HEADER, fact_row

RATES = Rates({"UZS": 1.0, "USD": 12_000.0})
TODAY = date(2026, 10, 15)  # четверг
END = date(2026, 10, 31)
SINCE = date(2026, 10, 1)


def record(
    repeat: str = "once",
    start: date = date(2026, 10, 17),
    amount: float = 320_000,
    sub: str = "развитие",
    record_id: str = "k7f2qa",
    weekdays: frozenset[int] = frozenset(),
) -> CalendarRecord:
    return CalendarRecord(
        record_id, start, repeat, weekdays, "👶 ДЕТИ", sub, "UZS", amount, "", "Тест"
    )


def facts(*rows: list[Any]) -> Any:
    return transactions_frame([FACT_HEADER, *rows], RATES)


def state(
    rows: Sequence[list[Any]] = (),
    records: Sequence[CalendarRecord] = (),
    used: frozenset[int] = frozenset(),
) -> CalendarState:
    return calendar_state(facts(*rows), records, TODAY, END, SINCE, used, used)

def test_records_are_open_on_their_days() -> None:
    coffee = record("daily", date(2026, 10, 1), 30_000, "кофе", "m3a9zt")
    found = state(records=[record(), coffee])
    kids = [
        (o.day.day, o.morning, o.now) for o in found.occurrences if o.record == record()
    ]
    assert kids == [(17, 320_000, 320_000)]
    assert len([o for o in found.occurrences if o.record == coffee]) == 17
    assert [o.day.day for o in found.occurrences][:4] == [15, 16, 17, 17]
    assert found.closed_morning == found.closed_now == frozenset()


def test_a_one_off_paid_early_is_closed_by_one_payment() -> None:
    tomorrow = record(start=date(2026, 10, 16))
    paid = fact_row(date(2026, 10, 14), "👶 ДЕТИ", "развитие", 310_000)  # ±10 %
    book = fact_row(date(2026, 10, 14), "👶 ДЕТИ", "развитие", 30_000)

    assert (only.day.day, only.morning, only.now) == (16, 0, 0)
    assert found.closed_morning == found.closed_now == frozenset({0})
```

```python
"""Календарь записей: лист «Календарь» → записи, их дни в месяце, закрытие фактом,
подсказки сумм. Без сети: на входе значения листа и фрейм fact.

Запись — часть плана статьи (подкатегория + валюта) на день: разовая, каждый день,
по дням недели или раз в месяц. У вхождения записи в день два «открыто»: на утро —
без сегодняшних операций (резерв статьи и план в день за день не меняются) и на
сейчас — с ними (события прогноза и суммы на экране).
"""

import calendar
import logging
import secrets
import string
from collections.abc import Collection, Mapping, Sequence
from dataclasses import dataclass
from datetime import date, timedelta
from statistics import median
from typing import Any

import pandas as pd

from app.services.analytics_service import expenses, to_day
from app.services.google_sheets import CALENDAR_HEADER as HEADER

logger = logging.getLogger(__name__)

REPEATS = {
    "нет": "once",
    "каждый день": "daily",
    "по дням недели": "weekdays",
    "раз в месяц": "monthly",
}
REPEAT_TEXT = {code: text for text, code in REPEATS.items()}
WEEKDAYS = ("пн", "вт", "ср", "чт", "пт", "сб", "вс")  # ISO: пн = 1 … вс = 7
EARLY_DAYS = 3  # разовую запись закрывает операция с её даты минус 3 дня
TOLERANCE = 0.1  # операция на сумму записи ±10 %
DONE_SHARE = 0.9  # траты дня покрыли 90 % — сегодняшние вхождения статьи закрыты
HINT_DAYS = 90  # «обычно» и «в прошлый раз» — по операциям за 90 дней
PER_DAY_DAYS = 30  # «в среднем в день» — за 30 дней
ID_LENGTH = 6


@dataclass(frozen=True)
class CalendarRecord:
    """Строка листа «Календарь»: сумма положительная, в валюте статьи."""

    id: str
    start: date  # день разовой записи или первый день повтора
    repeat: str  # once | daily | weekdays | monthly
    weekdays: frozenset[int]  # ISO-номера дней для weekdays, иначе пусто
    group: str
    subcategory: str
    currency: str
    amount: float
    name: str  # пусто — показывается подкатегория
    author: str

    @property
    def key(self) -> str:
        return f"{self.subcategory}|{self.currency}"

    @property
    def title(self) -> str:
        return self.name or self.subcategory


@dataclass(frozen=True)
class Occurrence:
    """Вхождение записи в день: сколько открыто на утро и на сейчас."""

    record: CalendarRecord
    day: date
    morning: float  # без сегодняшних операций — для резерва статьи
    now: float  # с ними — события прогноза и суммы на экране; 0 — закрыто
    covered: float  # сегодня: засчитано из трат статьи; в другие дни 0


@dataclass(frozen=True)
class CalendarState:
    occurrences: tuple[Occurrence, ...]  # по дням, потом по началу записи
    closed_morning: frozenset[int]  # строки fact, закрывшие разовые записи по вчера
    closed_now: frozenset[int]  # то же по сегодня


@dataclass(frozen=True)
class Hint:
    """Подсказка суммы для окна записи; None — в истории статьи пусто."""

    typical: float | None  # медиана операций за HINT_DAYS дней
    last: float | None  # последняя операция
    per_day: float | None  # сумма за PER_DAY_DAYS дней / PER_DAY_DAYS


def _text(value: Any) -> str:
    return "" if value is None else str(value).strip()


def _number(value: Any) -> float | None:
    if isinstance(value, bool):
        return None
    if isinstance(value, int | float):
        return float(value)
    text = _text(value).replace("\u00a0", "").replace(" ", "").replace(",", ".")
    try:
        return float(text)
    except ValueError:
        return None


def _weekdays(text: str) -> frozenset[int] | None:
    """«пн ср» → {1, 3}; незнакомое слово — None."""
    found: set[int] = set()
    for word in text.lower().replace(",", " ").split():
        if word not in WEEKDAYS:
            return None
        found.add(WEEKDAYS.index(word) + 1)
    return frozenset(found)


def read_calendar(rows: Sequence[Sequence[Any]]) -> tuple[CalendarRecord, ...]:
    """Значения листа (UNFORMATTED, первая строка — шапка) → записи.

    Строка без ID, даты, статьи или суммы, с незнакомым повтором или без дней у
    «по дням недели» пропускается и пишется в лог.
    """
    found: list[CalendarRecord] = []
    for number, row in enumerate(rows[1:], start=2):
        cells = list(row[: len(HEADER)]) + [""] * (
            len(HEADER) - len(row[: len(HEADER)])
        )
        record_id, start = _text(cells[0]), to_day(cells[1])
        repeat = REPEATS.get(_text(cells[2]).lower())
        days = _weekdays(_text(cells[3])) if repeat == "weekdays" else frozenset()
        group, sub, currency = _text(cells[4]), _text(cells[5]), _text(cells[6])
        amount = _number(cells[7])
        valid = (
            record_id
            and start is not None
            and repeat is not None
            and days is not None
            and (repeat != "weekdays" or days)
            and group
            and sub
            and currency
            and amount is not None
            and amount > 0
        )
        if not valid:
            if any(_text(cell) for cell in cells):
                logger.warning("Calendar row %s is skipped: %s", number, cells)
            continue
        found.append(
            CalendarRecord(
                record_id,
                start,
                repeat,
                days,
                group,
                sub,
                currency.upper(),
                amount,
                _text(cells[8]),
                _text(cells[9]),
            )
        )
    return tuple(found)


def _falls(record: CalendarRecord, day: date) -> bool:
    if record.repeat == "daily":
        return True
    if record.repeat == "weekdays":
        return day.isoweekday() in record.weekdays
    last = calendar.monthrange(day.year, day.month)[1]
    return day.day == min(record.start.day, last)  # 31-е в коротком месяце — последний


def occurrences(record: CalendarRecord, first: date, last: date) -> list[date]:
    """Дни записи с first по last включительно."""
    if record.repeat == "once":
        return [record.start] if first <= record.start <= last else []
    found: list[date] = []
    day = max(first, record.start)
    while day <= last:
        if _falls(record, day):
            found.append(day)
        day += timedelta(days=1)
    return found


def record_row(record: CalendarRecord) -> list[Any]:
    """Строка листа A:J для записи как есть (RAW): дата — «ДД.ММ.ГГГГ» текстом."""
    return [
        record.id,
        f"{record.start:%d.%m.%Y}",
        REPEAT_TEXT[record.repeat],
        " ".join(WEEKDAYS[day - 1] for day in sorted(record.weekdays)),
        record.group,
        record.subcategory,
        record.currency,
        record.amount,
        record.name,
        record.author,
    ]


def new_id(taken: Collection[str]) -> str:
    """Код записи: буква и пять букв или цифр, которого ещё нет на листе."""
    alphabet = string.ascii_lowercase + string.digits
    while True:
        code = secrets.choice(string.ascii_lowercase) + "".join(
            secrets.choice(alphabet) for _ in range(ID_LENGTH - 1)
        )
        if code not in taken:
            return code


def _spending(frame: pd.DataFrame) -> pd.DataFrame:
    """Операции трат: без доходов и переводов, возвраты не в счёт."""
    spent = expenses(frame)
    return spent[spent["amount"] > 0]


def _close_once(
    spent: pd.DataFrame,
    records: Sequence[CalendarRecord],
    since: date,
    through: date,
    used: frozenset[int],
    closed: Mapping[str, int],
) -> dict[str, int]:
    """Разовые записи, закрытые одной операцией заранее: ID записи → строка fact.

    Записи с датой с since — по порядку дат; операция — той же статьи на сумму
    записи ±TOLERANCE с даты минус EARLY_DAYS по дату (не позже through), не из
    used и не взятая другой записью; из кандидатов — ближайшая по сумме, потом по
    дате. closed — уже закрытые записи: они и их операции остаются как были.
    """
    found = dict(closed)
    taken = set(found.values())
    once = sorted(
        (r for r in records if r.repeat == "once" and r.start >= since),
        key=lambda record: (record.start, record.id),
    )
    for record in once:
        if record.id in found:
            continue
        opens = record.start - timedelta(days=EARLY_DAYS)
        mask = (
            (spent["subcategory"] == record.subcategory)
            & (spent["currency"] == record.currency)
            & (spent["day"] >= opens)
            & (spent["day"] <= min(record.start, through))
        )
        best: tuple[tuple[float, int], int] | None = None
        rows = spent[mask]
        for index, day, amount in zip(
            rows.index, rows["day"], rows["amount"], strict=True
        ):
            number = int(index)
            gap = abs(float(amount) - record.amount)
            if number in used or number in taken or gap > TOLERANCE * record.amount:
                continue
            key = (gap, abs((day - record.start).days))
            if best is None or key < best[0]:
                best = (key, number)
        if best is not None:
            taken.add(best[1])
            found[record.id] = best[1]
    return found


def calendar_state(
    frame: pd.DataFrame,
    records: Sequence[CalendarRecord],
    today: date,
    last: date,
    since: date,
    used_morning: frozenset[int],
    used_now: frozenset[int],
) -> CalendarState:
    """Вхождения записей с today по last и операции, закрывшие разовые записи.

    since — с какой даты разовые записи ищут свою операцию (для темпа нужны и
    прошедшие); used_* — строки fact, которыми закрыты платежи жёлтого списка к утру
    и на сейчас: записям они не достаются.
    """
    spent = _spending(frame)
    morning = _close_once(
        spent, records, since, today - timedelta(days=1), used_morning, {}
    )
    now = _close_once(spent, records, since, today, used_now, morning)
    closed_now = frozenset(now.values())
    todays = spent[
        (spent["day"] == today) & ~spent.index.isin(list(used_now | closed_now))
    ]
    spent_today = todays.groupby(["subcategory", "currency"])["amount"].sum()
    days = {record.id: occurrences(record, today, last) for record in records}
    due: dict[tuple[str, str], float] = {}  # статья → Σ сегодняшних открытых вхождений
    for record in records:
        if today in days[record.id] and record.id not in now:
            article = (record.subcategory, record.currency)
            due[article] = due.get(article, 0.0) + record.amount
    share = {
        article: min(float(spent_today.get(article, 0.0)) / total, 1.0)
        for article, total in due.items()
    }
    found: list[Occurrence] = []
    for record in records:
        morning_open = 0.0 if record.id in morning else record.amount
        for day in days[record.id]:
            if record.id in now:
                found.append(Occurrence(record, day, morning_open, 0.0, 0.0))
            elif day != today:
                found.append(Occurrence(record, day, morning_open, record.amount, 0.0))
            else:
                part = share.get((record.subcategory, record.currency), 0.0)
                covered = record.amount * part
                left = 0.0 if part >= DONE_SHARE else record.amount - covered
                found.append(Occurrence(record, day, morning_open, left, covered))
    found.sort(key=lambda item: (item.day, item.record.start, item.record.id))
    return CalendarState(tuple(found), frozenset(morning.values()), closed_now)


def _rounded(value: float, currency: str) -> float:
    """Сумы — до тысячи, остальные валюты — до целых."""
    return float(round(value, -3)) if currency == "UZS" else float(round(value))


def hints(frame: pd.DataFrame, today: date) -> dict[str, Hint]:
    """Подсказки сумм по статьям «подкатегория|валюта» из истории трат до сегодня."""
    spent = _spending(frame)
    window = spent[
        (spent["day"] >= today - timedelta(days=HINT_DAYS)) & (spent["day"] < today)
    ]
    found: dict[str, Hint] = {}
    for (sub, currency), rows in window.groupby(["subcategory", "currency"]):
        ordered = rows.sort_values("day", kind="stable")
        recent = rows[rows["day"] >= today - timedelta(days=PER_DAY_DAYS)]
        per_day = float(recent["amount"].sum()) / PER_DAY_DAYS if len(recent) else None
        found[f"{sub}|{currency}"] = Hint(
            _rounded(float(median(rows["amount"])), str(currency)),
            _rounded(float(ordered["amount"].iloc[-1]), str(currency)),
            None if per_day is None else _rounded(per_day, str(currency)),
        )
    return found
```

```python
class CalendarWorksheet:
    def __init__(self, rows: list[list[Any]] | None = None) -> None:
        self.id = 7
        self.rows = rows if rows is not None else []
        self.reads = 0
        self.appended: list[tuple[list[list[Any]], dict[str, Any]]] = []
        self.updates: list[dict[str, Any]] = []

    def get_all_values(self, **options: Any) -> list[list[Any]]:
        self.reads += 1
        return [list(row) for row in self.rows]

    def col_values(self, column: int) -> list[Any]:
        return [row[column - 1] if len(row) >= column else "" for row in self.rows]

    def append_rows(self, values: list[list[Any]], **options: Any) -> None:
        self.appended.append((values, options))
        self.rows.extend(list(row) for row in values)

    def update(self, **options: Any) -> None:
        self.updates.append(options)


class CalendarSpreadsheet:
    def __init__(self, worksheet: CalendarWorksheet | None) -> None:
        self.ws = worksheet
        self.created: list[tuple[str, int, int]] = []
        self.batch: list[dict[str, Any]] = []

    def worksheet(self, name: str) -> CalendarWorksheet:
        if self.ws is None:
            raise WorksheetNotFound(name)
        return self.ws

    def add_worksheet(self, title: str, rows: int, cols: int) -> CalendarWorksheet:
        self.created.append((title, rows, cols))
        self.ws = CalendarWorksheet()
        return self.ws

    def batch_update(self, body: dict[str, Any]) -> None:
        self.batch.append(body)

    service._balance_cells = None
    service._calendar = None
    service._authenticate = lambda: None
    return service
```

```python
def below_zero(value: float) -> bool:
    return value < -CENT


def month_end(today: date) -> date:
    return today.replace(day=calendar.monthrange(today.year, today.month)[1])


def dip(days: Sequence[int], values: Sequence[float]) -> Dip | None:
    """Первый день ниже нуля и первый день после него не ниже; None — минуса нет."""
    start = next((i for i, value in enumerate(values) if below_zero(value)), None)
    if start is None:
        return None
    back = next(
        (i for i in range(start + 1, len(values)) if not below_zero(values[i])), None
    )
    return Dip(days[start], None if back is None else days[back])


def _paid(receipts: Mapping[int, Receipt]) -> frozenset[int]:
    """Строки fact, которыми закрыты строки списка."""
    return frozenset(i for receipt in receipts.values() for i in receipt.operations)


def _money_now(frame: pd.DataFrame, code: str, today: date) -> float:
    """Доходы плюсом, остальное с обратным знаком колонки D — по сегодня."""
    own = frame[(frame["currency"] == code) & (frame["day"] <= today)]
    flow = own["amount"].where(own["group"] == INCOME_GROUP, -own["amount"])
    return float(flow.sum())


def _spent(
    frame: pd.DataFrame, code: str, first: date, last: date, paid: frozenset[int]
) -> float:
    """Траты валюты с first по last: без доходов, переводов и платежей списка."""
    spent = expenses(frame)
    mask = (
        (spent["currency"] == code)
        & (spent["day"] >= first)
        & (spent["day"] <= last)
        & ~spent.index.isin(list(paid))
    )
    return float(spent.loc[mask, "amount"].sum())


def _book(
    frame: pd.DataFrame,
    articles: Sequence[PlanArticle],
    state: CalendarState,
    code: str,
    today: date,
) -> tuple[ArticleState, ...]:
    """Статьи трат валюты: план, остаток (план − факт с 1-го по вчера), записи на утро.

    Строки одной подкатегории складываются; у статьи записи без строки во вкладке
    план 0 — её записи целиком сверх плана.
    """
    plans: dict[str, tuple[str, float]] = {}
    for article in articles:
        if article.kind == "spend" and article.currency == code:
            group, plan = plans.get(article.subcategory, (article.group, 0.0))
            plans[article.subcategory] = (group, plan + article.plan)
    booked: dict[str, float] = {}
    groups: dict[str, str] = {}
    for occurrence in state.occurrences:
        sub = occurrence.record.subcategory
        booked[sub] = booked.get(sub, 0.0) + occurrence.morning
        groups.setdefault(sub, occurrence.record.group)
    month = frame[
        (frame["currency"] == code)
        & (frame["day"] >= today.replace(day=1))
        & (frame["day"] < today)
    ]
    facts = month.groupby("subcategory")["amount"].sum()
    found: list[ArticleState] = []
    for sub in [*plans, *(name for name in booked if name not in plans)]:
        group, plan = plans.get(sub, (groups.get(sub, ""), 0.0))
        rest = max(plan - float(facts.get(sub, 0.0)), 0.0)
        found.append(ArticleState(group, sub, code, plan, rest, booked.get(sub, 0.0)))
    return tuple(found)


def _spread(book: Sequence[ArticleState]) -> float:
    """Остаток статей после резерва записей — его план раскладывает по дням."""
    return sum(article.rest - min(article.booked, article.rest) for article in book)


def _unpaid(
    items: Sequence[ListItem], morning: Mapping[int, Receipt], code: str
) -> float:
    """Неоплаченные к утру платежи списка валюты — положительной суммой."""
    return -sum(
        remaining(item, morning.get(item.row, NOTHING))
        for item in items
        if item.currency == code and item.amount < 0
    )


def _calendar(
    frame: pd.DataFrame,
    records: Sequence[CalendarRecord],
    morning: Mapping[int, Receipt],
    now: Mapping[int, Receipt],
    today: date,
    code: str,
) -> CalendarState:
    """Вхождения записей валюты; операции платежей списка записям не достаются."""
    return calendar_state(
        frame,
        [record for record in records if record.currency == code],
        today,
        month_end(today),
        today - timedelta(days=PACE_DAYS),
        _paid(morning),
        _paid(now),
    )


def _share(
    spreads: Mapping[str, float],
    unpaid: Mapping[str, float],
    rates: Rates,
    codes: Sequence[str],
) -> dict[str, float]:
    """Сколько плана статей ещё разложить по дням в каждой валюте.

    Неоплаченный платёж списка вычитается из статей своей валюты. Если их не
    хватает (платёж в долларах, а статья в сумах), остаток по курсу таблицы
    снимается со статей других валют, сначала сумов: как и вкладка, прогноз не
    считает платёж дважды — днями в одной валюте и событием в другой.
    """
    left: dict[str, float] = {}
    extra = 0.0  # в сумах: платежи, которым не хватило статей своей валюты
    for code in codes:
        left[code] = max(spreads[code] - unpaid[code], 0.0)
        extra += max(unpaid[code] - spreads[code], 0.0) * rates.to_uzs.get(code, 0.0)
    for code in codes:
        rate = rates.to_uzs.get(code)
        if not rate or extra <= 0:
            continue
        taken = min(left[code] * rate, extra)
        left[code] -= taken / rate
        extra -= taken
    return left


def _events(
    items: Sequence[ListItem], now: Mapping[int, Receipt], code: str, today: date
) -> tuple[Event, ...]:
    """Незакрытые строки списка валюты: остаток в их день, опоздавшие — сегодня."""
    last = month_end(today).day
    found: list[Event] = []
    for item in items:
        if item.currency != code:
            continue
        rest = remaining(item, now.get(item.row, NOTHING))
        if not rest:
            continue
        day = min(item.day, last)  # 31-е в коротком месяце — его последний день
        late = day < today.day
        found.append(Event(today.day if late else day, item.name, rest, late))
    return tuple(sorted(found, key=lambda event: event.day))


def _moves(
    events: Sequence[Event], occurrences: Sequence[Occurrence], once_only: bool
) -> dict[int, float]:
    """Движения денег по дням: строки списка и открытое на сейчас у записей."""
    moves: dict[int, float] = {}
    for event in events:
        moves[event.day] = moves.get(event.day, 0.0) + event.amount
    for occurrence in occurrences:
        if occurrence.now and (not once_only or occurrence.record.repeat == "once"):
            day = occurrence.day.day
            moves[day] = moves.get(day, 0.0) - occurrence.now
    return moves


def _line(
    now: float,
    moves: Mapping[int, float],
    per_day: float,
    spent_today: float,
    today: date,
) -> list[float]:
    """Остаток на вечер каждого дня: за сегодня — только то, что от дня осталось."""
    left = now + moves.get(today.day, 0.0) - max(per_day - spent_today, 0.0)
    values = [left]
    for number in range(today.day + 1, month_end(today).day + 1):
        left += moves.get(number, 0.0) - per_day
        values.append(left)
    return values


def currency_forecast(
    frame: pd.DataFrame,
    articles: Sequence[PlanArticle],
    items: Sequence[ListItem],
    today: date,
    code: str,
    plan_left: float | None = None,
    records: Sequence[CalendarRecord] = (),
) -> CurrencyForecast:
    """Прогноз одной валюты с сегодня по последний день месяца.

    plan_left — сколько плана статей разложить по дням (month_forecast делит его
    между валютами); None — статьи своей валюты без резерва записей и без её
    неоплаченных платежей. records — записи календаря всех валют.
    """
    first = today.replace(day=1)
    yesterday = today - timedelta(days=1)
    morning = match_receipts(frame, items, first, yesterday)
    now = match_receipts(frame, items, first, today)
    state = _calendar(frame, records, morning, now, today, code)
    start = today - timedelta(days=PACE_DAYS)
    paid_morning = _paid(morning) | state.closed_morning
    pace = max(_spent(frame, code, start, yesterday, paid_morning) / PACE_DAYS, 0.0)
    spent = _spent(frame, code, today, today, _paid(now) | state.closed_now)
    covered = sum(item.covered for item in state.occurrences)
    covered_once = sum(
        item.covered for item in state.occurrences if item.record.repeat == "once"
    )
    book = _book(frame, articles, state, code, today)
    if plan_left is None:
        plan_left = max(_spread(book) - _unpaid(items, morning, code), 0.0)
    per_day = plan_left / ((month_end(today) - today).days + 1)
    events = _events(items, now, code, today)
    money = _money_now(frame, code, today)
    spent_plan = max(spent - covered, 0.0)
    plan = _line(
        money, _moves(events, state.occurrences, False), per_day, spent_plan, today
    )
    spent_pace = max(spent - covered_once, 0.0)
    paced = _line(
        money, _moves(events, state.occurrences, True), pace, spent_pace, today
    )
    over = {
        article.subcategory for article in book if article.booked > article.rest + CENT
    }
    numbers = list(range(today.day, month_end(today).day + 1))
    return CurrencyForecast(
        code,
        money,
        per_day,
        pace,
        spent_plan,
        events,
        tuple(
            Evening(number, by_plan, by_pace)
            for number, by_plan, by_pace in zip(numbers, plan, paced, strict=True)
        ),
        dip(numbers, plan),
        dip(numbers, paced),
        tuple(
            RecordDay(
                item.record.id,
                item.day.day,
                item.record.title,
                item.record.group,
                item.record.subcategory,
                item.record.repeat,
                item.record.amount,
                item.now,
                item.record.subcategory in over,
            )
            for item in state.occurrences
        ),
        book,
    )


def currency_order(codes: Iterable[str]) -> list[str]:
    """UZS, USD, RUB, остальные по алфавиту; без повторов и пустых."""
    unique = {code for code in codes if code}
    return [code for code in ORDER if code in unique] + sorted(unique - set(ORDER))


def _month_records(
    lines: Sequence[CurrencyForecast],
    records: Sequence[CalendarRecord],
    booked: Mapping[str, float],
    today: date,
) -> tuple[RecordMonth, ...]:
    """Записи для списка: все повторы и разовые с сегодня (и в следующих месяцах) —
    чтобы любую можно было открыть и поправить; сначала повторы, потом разовые."""
    totals: dict[str, float] = {}
    over: dict[str, bool] = {}
    for line in lines:
        for day in line.records:
            totals[day.id] = totals.get(day.id, 0.0) + day.open
            over[day.id] = over.get(day.id, False) or day.over
    shown = sorted(
        (r for r in records if r.repeat != "once" or r.start >= today),
        key=lambda record: (record.repeat == "once", record.start, record.id),
    )
    return tuple(
        RecordMonth(
            record,
            totals.get(record.id, 0.0),
            booked.get(record.id, 0.0),
            over.get(record.id, False),
        )
        for record in shown
    )


def month_forecast(
    frame: pd.DataFrame,
    articles: Sequence[PlanArticle],
    items: Sequence[ListItem],
    today: date,
    rates: Rates,
    currencies: Iterable[str],
    records: Sequence[CalendarRecord] = (),
) -> MonthForecast:
    """Прогноз по валютам карт и всего — по сегодняшним курсам таблицы."""
    codes = currency_order(currencies)
    first = today.replace(day=1)
    morning = match_receipts(frame, items, first, today - timedelta(days=1))
    now = match_receipts(frame, items, first, today)
    spreads: dict[str, float] = {}
    unpaid: dict[str, float] = {}
    booked: dict[str, float] = {}  # ID записи → её открытое на утро с сегодня
    for code in codes:
        state = _calendar(frame, records, morning, now, today, code)
        spreads[code] = _spread(_book(frame, articles, state, code, today))
        unpaid[code] = _unpaid(items, morning, code)
        for occurrence in state.occurrences:
            key = occurrence.record.id
            booked[key] = booked.get(key, 0.0) + occurrence.morning
    left = _share(spreads, unpaid, rates, codes)
    lines = tuple(
        currency_forecast(frame, articles, items, today, code, left[code], records)
        for code in codes
    )
    rated = [(line, rate) for line in lines if (rate := rates.to_uzs.get(line.code))]
    numbers = list(range(today.day, month_end(today).day + 1))
    plans = [0.0] * len(numbers)
    paces = [0.0] * len(numbers)
    for line, rate in rated:
        for index, point in enumerate(line.days):
            plans[index] += point.plan * rate
            paces[index] += point.pace * rate
    uzs = tuple(
        Evening(number, plan, pace)
        for number, plan, pace in zip(numbers, plans, paces, strict=True)
    )
    dollar = rates.to_uzs.get("USD")
    usd = (
        tuple(Evening(p.day, p.plan / dollar, p.pace / dollar) for p in uzs)
        if dollar
        else ()
    )
    return MonthForecast(
        today,
        month_end(today),
        lines,
        frozenset(line.code for line, _ in rated),
        uzs,
        usd,
        dip(numbers, [point.plan for point in uzs]),
        dip(numbers, [point.pace for point in uzs]),
        _month_records(lines, records, booked, today),
        hints(frame, today),
        {code: rate for code, rate in rates.to_uzs.items() if code != "UZS"},
    )
```

```python
class CalendarSheets:
    """Лист «Календарь» в памяти с теми же методами, что у GoogleSheetsService."""

    def __init__(self, rows: list[list[Any]] | None = None) -> None:
        self.rows = [list(HEADER), *(rows or [])]
        self.fail = False

    def get_calendar(self) -> list[list[Any]]:
        return [list(row) for row in self.rows]

    def add_calendar_row(self, row: list[Any]) -> None:
        if self.fail:
            raise ConnectionError("Google is down")
        self.rows.append(list(row))

    def update_calendar_row(self, record_id: str, row: list[Any]) -> bool:
        for index, current in enumerate(self.rows[1:], start=1):
            if current[0] == record_id:
                self.rows[index] = list(row)
                return True
        return False

    def delete_calendar_row(self, record_id: str) -> bool:
        for index, current in enumerate(self.rows[1:], start=1):
            if current[0] == record_id:
                del self.rows[index]
                return True
        return False
```

```python
                currency=item.record.currency,

                author=item.record.author,
                month_total=_rounded(item.month_total, item.record.currency),
                booked=_rounded(item.booked, item.record.currency),
                over=item.over,
            )
            for item in found.calendar
        ],
        articles=[

def _records_out(records: Sequence[Any], code: str) -> list[ForecastRecordOut]:
    found = []
    for day in records:
        left = _rounded(day.open, code)
        found.append(
            ForecastRecordOut(
                id=day.id,
                day=day.day,
                name=day.name,
                group=day.group,
                subcategory=day.subcategory,
                repeat=day.repeat,
                amount=_rounded(day.amount, code),
                open=left,
                done=left == 0,
                over=day.over,
            )
        )
    return found


def check_record(
    body: CalendarIn,
    bot_data: Mapping[str, Any],
    today: date,
    current: CalendarRecord | None,
) -> set[str]:
    """Поля записи, которые не подходят: статья трат справочника, валюта карт,
    дата с сегодня и не дальше года (у правки повтора — можно прежнюю), дни недели."""
    bad: set[str] = set()
    groups: list[str] = bot_data.get("categories", [])
    subcategories: dict[str, list[str]] = bot_data.get("subcategories", {})
    if body.group not in groups or body.group in CLOSED_GROUPS:
        bad.add("group")
    elif body.subcategory not in subcategories.get(body.group, []):
        bad.add("subcategory")
    cards = {currency_of(source) for source in bot_data.get("sources", [])}
    if body.currency not in cards:
        bad.add("currency")
    kept = current is not None and body.repeat != "once" and body.date == current.start
    latest = today + timedelta(days=MAX_AHEAD_DAYS)
    if not kept and not today <= body.date <= latest:
        bad.add("date")
    if body.repeat == "weekdays":
        if not body.weekdays or any(day not in range(1, 8) for day in body.weekdays):
            bad.add("weekdays")
    elif body.weekdays:
        bad.add("weekdays")
    return bad

    return CalendarRecord(

def add_record_row(gs: Any, body: CalendarIn, author: str) -> CalendarRecord:
    """Новая запись с кодом, которого ещё нет на листе."""

def record_note(action: str, author: str, record: CalendarRecord) -> str:
    """«📅 Иван — новая запись: 17.10 Детский центр 320 000 UZS (ДЕТИ / развитие)»;
    без имени — «📅 Новая запись: …». Как у плана: имя через тире, без рода."""
    if record.repeat == "daily":
        when = f"каждый день с {record.start:%d.%m}"

    head = f"{author} — {action}" if author else action[:1].upper() + action[1:]
    return (
        f"📅 {head}: {when} {record.title} {value} "
        f"{record.currency} ({group} / {record.subcategory})"
```

```python
    async def calendar_body(request: Request) -> CalendarIn | JSONResponse:
        try:
            return CalendarIn.model_validate_json(await request.body())
        except ValidationError as error:
            return validation_error(
                {str(e["loc"][0]) if e["loc"] else "body" for e in error.errors()}

    async def add_record(request: Request) -> JSONResponse:
        user = current_user(request)
        body = await calendar_body(request)
        if isinstance(body, JSONResponse):
            return body
        today = local_today(config.ANALYTICS_TIMEZONE)
        if bad := check_record(body, application.bot_data, today, None):
            return validation_error(bad)
        entries: dict[str, None] = user_context(
            application, user.id
        ).user_data.setdefault(CALENDAR_ENTRIES, {})
        key = str(body.entry_id) if body.entry_id else None
        if key is not None and key in entries:
            return await fresh_forecast(user.id)  # повтор нажатия: строка уже есть
        if key is not None:
            entries[key] = None
            while len(entries) > ENTRY_LIMIT:
                entries.pop(next(iter(entries)))
        author = await author_name(application.bot, user) or ""
        gs = application.bot_data["gs_service"]
        try:
            record = await asyncio.to_thread(add_record_row, gs, body, author)
        except Exception:
            if key is not None:
                entries.pop(key, None)
            logger.exception("Calendar write failed for user_id=%s", user.id)
            return error_response(503, "sheets_unavailable", SHEETS_DOWN)
        logger.info("Calendar record %s added by user_id=%s", record.id, user.id)
        await notify_others(
            application.bot, user.id, record_note("новая запись", author, record)
        )
        return await fresh_forecast(user.id)

    async def update_record(request: Request) -> JSONResponse:
        user = current_user(request)
        record_id = request.path_params["record_id"]
        body = await calendar_body(request)
        if isinstance(body, JSONResponse):
            return body
        gs = application.bot_data["gs_service"]
        try:
            current = await asyncio.to_thread(find_record, gs, record_id)
        except Exception:
            logger.exception("Calendar read failed for user_id=%s", user.id)
            return error_response(503, "sheets_unavailable", SHEETS_DOWN)
        if current is None:
            return error_response(404, "record_not_found", RECORD_GONE)
        today = local_today(config.ANALYTICS_TIMEZONE)
        if bad := check_record(body, application.bot_data, today, current):
            return validation_error(bad)
        author = await author_name(application.bot, user) or ""
        record = record_from(body, record_id, author)
        try:
            found = await asyncio.to_thread(
                gs.update_calendar_row, record_id, record_row(record)
            )
        except Exception:
            logger.exception("Calendar write failed for user_id=%s", user.id)
            return error_response(503, "sheets_unavailable", SHEETS_DOWN)
        if not found:
            return error_response(404, "record_not_found", RECORD_GONE)
        await notify_others(
            application.bot, user.id, record_note("запись изменена", author, record)
        )
        return await fresh_forecast(user.id)

    async def delete_record(request: Request) -> JSONResponse:
        user = current_user(request)
        record_id = request.path_params["record_id"]
        gs = application.bot_data["gs_service"]
        try:
            current = await asyncio.to_thread(find_record, gs, record_id)
            deleted = current is not None and await asyncio.to_thread(
                gs.delete_calendar_row, record_id
            )
        except Exception:
            logger.exception("Calendar write failed for user_id=%s", user.id)
            return error_response(503, "sheets_unavailable", SHEETS_DOWN)
        if current is None or not deleted:
            return error_response(404, "record_not_found", RECORD_GONE)
        author = await author_name(application.bot, user) or ""
        await notify_others(
            application.bot, user.id, record_note("запись удалена", author, current)
        )
        return await fresh_forecast(user.id)
```

```ts
/** Записи календаря на экране: правило словами, дни правила, суммы клеток, подсказки. */

import type {
  AmountHint,
  Forecast,
  ForecastArticle,
  ForecastRecord,
  Repeat,
} from "../api";
import { money } from "../format";
import { TOTAL, dayOf, isoDay, viewCurrencies, type View } from "./view";

/** Группы не трат: в окне записи их нет, API их не примет. */
export const CLOSED_GROUPS = ["💰 ДОХОДЫ", "💳 СЧЕТА"];
export const WEEKDAY_NAMES = ["пн", "вт", "ср", "чт", "пт", "сб", "вс"]; // ISO: пн = 1
export const REPEAT_NAMES: Record<Repeat, string> = {
  once: "Разово",
  daily: "Каждый день",
  weekdays: "По дням недели",
  monthly: "Раз в месяц",
};
const CENT = 0.01; // как на сервере: записи статьи больше остатка больше чем на копейку

/** «2026-10-15» → 4: пн = 1 … вс = 7. */
export function isoWeekday(iso: string): number {
  const day = new Date(`${iso}T00:00:00Z`).getUTCDay();
  return day === 0 ? 7 : day;
}

/** «👶 ДЕТИ» → «ДЕТИ». */
export function groupTitle(group: string): string {
  return group.replace(/^[^\p{L}\p{N}]+/u, "");
}

/** «разово», «каждый день», «пн ср», «15-го каждого месяца». */
export function ruleText(
  repeat: Repeat,
  weekdays: number[],
  date: string,
): string {
  if (repeat === "once") return "разово";
  if (repeat === "daily") return "каждый день";
  if (repeat === "weekdays") {
    return [...weekdays]
      .sort((a, b) => a - b)
      .map((day) => WEEKDAY_NAMES[day - 1] ?? "")
      .join(" ");
  }
  return `${dayOf(date)}-го каждого месяца`;
}

/** Дни правила с today по end (последний день того же месяца) — как вхождения на сервере. */
export function ruleDays(
  repeat: Repeat,
  weekdays: number[],
  date: string,
  today: string,
  end: string,
): number[] {
  if (date > end) return [];
  if (repeat === "once") return date >= today ? [dayOf(date)] : [];
  const last = dayOf(end);
  const found: number[] = [];
  for (let day = dayOf(date > today ? date : today); day <= last; day += 1) {
    const falls =
      repeat === "daily" ||
      (repeat === "weekdays" &&
        weekdays.includes(isoWeekday(isoDay(today, day)))) ||
      (repeat === "monthly" && day === Math.min(dayOf(date), last));
    if (falls) found.push(day);
  }
  return found;
}

/** Сколько записей статьи станет больше остатка: before — вклад правки до неё, after — после. */
export function overBy(
  article: ForecastArticle | undefined,
  before: number,
  after: number,
): number {
  const excess = (article?.booked ?? 0) - before + after - (article?.rest ?? 0);
  return excess > CENT ? excess : 0;
}

/** Недели сетки с понедельника: с недели сегодня по неделю последнего дня; null — не этот месяц. */
export function gridWeeks(today: string, end: string): (number | null)[][] {
  const last = dayOf(end);
  const weeks: (number | null)[][] = [];
  for (
    let monday = dayOf(today) - isoWeekday(today) + 1;
    monday <= last;
    monday += 7
  ) {
    const week: (number | null)[] = [];
    for (let day = monday; day < monday + 7; day += 1) {
      week.push(day >= 1 && day <= last ? day : null);
    }
    weeks.push(week);
  }
  return weeks;
}

export interface DayRecord extends ForecastRecord {
  currency: string;
}

/** Записи дня в виде — каждая со своей валютой. */
export function dayRecords(
  data: Forecast,
  view: View,
  day: number,
): DayRecord[] {
  return viewCurrencies(data, view).flatMap((line) =>
    line.records
      .filter((record) => record.day === day)
      .map((record) => ({ ...record, currency: line.code })),
  );
}

/** Открытое у записей дня в единицах вида: во «Всего» — по курсам таблицы. */
export function dayRecordSum(data: Forecast, view: View, day: number): number {
  const records = dayRecords(data, view, day);
  if (view.scope !== TOTAL) {
    return records.reduce((sum, record) => sum + record.open, 0);
  }
  let uzs = 0;
  for (const record of records) {
    const rate = record.currency === "UZS" ? 1 : data.rates[record.currency];
    if (rate) uzs += record.open * rate; // без курса валюта не во «Всего»
  }
  if (view.unit !== "usd") return uzs;
  const dollar = data.rates.USD;
  return dollar ? uzs / dollar : 0;
}

/** Сумма записей в клетке: сумы — «350к», «1,2м»; остальное — целыми. */
export function cellAmount(value: number, code: string): string {
  if (code !== "UZS") return money(value);
  if (value >= 999_500) {
    return `${(value / 1_000_000).toFixed(1).replace(".", ",")}м`;
  }
  if (value >= 1_000) return `${Math.round(value / 1_000)}к`;
  return money(value);
}

}

/** Подсказки суммы: «обычно» и «в прошлый раз», у «каждый день» — «в среднем в день». */
export function hintChips(
  hint: AmountHint | undefined,
  repeat: Repeat,
): HintChip[] {
  if (!hint) return [];

    repeat === "daily"

          ["обычно", hint.typical],

    value !== null && value > 0
      ? [{ label: `${label} ${money(value)}`, value }]

}
```

```tsx
    `rounded-lg px-2 py-1 text-sm font-medium ${on ? "bg-bg shadow-sm" : "text-hint"}`;
  return (
    <div className="flex gap-2">
      <div
        role="radiogroup"
        aria-label="Что показать"
        className="grid flex-1 auto-cols-fr grid-flow-col gap-1 rounded-xl bg-section p-1"
      >
        {scopes(data).map((scope) => (
          <button
            key={scope}
            type="button"
            role="radio"
            aria-checked={view.scope === scope}
            className={button(view.scope === scope)}
            onClick={() => onView({ ...view, scope })}
          >
            {scope === TOTAL ? "Всего" : scope}
          </button>
        ))}
      </div>
      {view.scope === TOTAL && hasDollars(data) && (
        <div
          role="radiogroup"
          aria-label="Единица"
          className="grid grid-cols-2 gap-1 rounded-xl bg-section p-1"
        >
          {(["uzs", "usd"] as const).map((unit) => (
            <button
              key={unit}
              type="button"
              role="radio"
              aria-checked={view.unit === unit}
              className={button(view.unit === unit)}
              onClick={() => onView({ ...view, unit })}
            >
              {unit === "uzs" ? "сум" : "$"}
            </button>
          ))}
        </div>
      )}
    </div>
  );
}

/** Выбранный день, если он ещё в прогнозе; иначе сегодня. */
function shownDay(data: Forecast, selected: number | null): number {
  const today = dayOf(data.today);
  const end = data.end ? dayOf(data.end) : today;
  return selected !== null && selected >= today && selected <= end
    ? selected
    : today;
}

interface MonthProps {

  day: number;

  onSelect: (day: number) => void;

}

function Month({
  data,
  view,
  day,
  onView,
  onSelect,
  onAdd,
  onEdit,
}: MonthProps) {
  const end = data.end ? dayOf(data.end) : dayOf(data.today);
  const code = viewCode(view);
  const days = viewDays(data, view);
  const last = days[days.length - 1];
  const ends = last

    : "";
  return (

      {warnings(data, view).map((text) => (
        <p key={text} className="text-sm font-medium text-danger">

        </p>
      ))}
      <MonthGrid data={data} view={view} selected={day} onSelect={onSelect} />
      <DayCard

        </div>

          label={`До конца месяца: ${ends}`}

        />
        {last && (
          <p className="flex flex-wrap gap-x-3 text-xs text-hint">
            <span>
              <span className="text-link">━</span>
              {` по плану ≈ ${amount(last.plan, code)}`}
            </span>
            <span>
              <span className="text-warn">╍</span>
              {` по темпу ≈ ${amount(last.pace, code)}`}
            </span>
          </p>
        )}
      </section>
      <RecordsList
        data={data}
        onAdd={onAdd && (() => onAdd(day))}
        onEdit={onEdit}
      />
      <section className="flex flex-col gap-1">
        <h2 className="font-semibold">
          {`По валютам: сейчас → ${shortDate(end, data.today)}`}
        </h2>
        <ul className="flex flex-col gap-1 text-sm">
          {currencyRows(data).map((row) => (
            <li
              key={row.code}
              className="grid grid-cols-[2.5rem_1fr_auto] items-baseline gap-2"
            >
              <span className="text-hint">{row.code}</span>
              <span>
                {row.now}{" "}
                <span className="whitespace-nowrap">
                  → <b>{row.end}</b>
                </span>
                {!row.counted && (
                  <span className="text-xs text-hint">
                    {" "}

              <span
                className={`text-xs ${row.minus ? "text-danger" : "text-hint"}`}
              >
                {row.pace}
              </span>
            </li>
          ))}
        </ul>
      </section>
      <p className="text-xs text-hint">{`${EXPLAIN} ${perDay(data, view)}`}</p>
    </>
  );
}

export default function ForecastScreen({ api }: { api: Api }) {
  const [data, setData] = useState<Forecast | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);
  const [version, setVersion] = useState(0);
  const [view, setView] = useState<View>(DEFAULT_VIEW);
  const [selected, setSelected] = useState<number | null>(null);

  useEffect(() => {
    let alive = true;
    api.forecast().then(
      (result) => {
        if (!alive) return;
        setData(result);
        setView(loadView(result));
        setError(null);
        setLoading(false);
      },
      (reason: unknown) => {
        if (!alive) return;
        setError(
          reason instanceof ApiError
            ? reason.message
            : "Не получилось загрузить прогноз",
        );
        setLoading(false);
      },
    );
    return () => {
      alive = false;
    };
  }, [api, version]);

  const refresh = useCallback(() => {
    setLoading(true);
    setVersion((current) => current + 1);
  }, []);
  const changeView = useCallback((next: View) => {
    setView(next);
    storeView(next);
  }, []);
  const day = data ? shownDay(data, selected) : 0;

  return (
    <div className="flex flex-col gap-4">
      <div className="flex items-center justify-between">
        <h1 className="text-lg font-semibold">
          {data ? `Прогноз · ${data.month}` : "Прогноз"}
        </h1>
        <button
          type="button"
          className="text-link disabled:opacity-50"
          disabled={loading}
          onClick={refresh}
        >
          Обновить
        </button>
      </div>
      {loading && !data && <Skeleton />}
      {error && (
        <div className="flex flex-col items-start gap-2" role="alert">
          <p>{error}</p>
          <button type="button" className="text-link" onClick={refresh}>
            Повторить
          </button>
        </div>
      )}
      {data?.status === "no_month_tab" && (
        <p>Нет вкладки месяца — прогноз появится, когда она будет</p>
      )}
      {data?.status === "ok" && (
        <Month
          data={data}
          view={view}
          day={day}
          onView={changeView}
          onSelect={setSelected}
        />
      )}
    </div>
  );
}
```

```tsx
import { useRef, useState } from "react";
import {
  ApiError,
  type Api,
  type Bootstrap,
  type CalendarRecord,
  type Forecast,
  type RecordInput,
  type Repeat,
} from "../api";
import { amountValue, apiAmount } from "../entry/amount";
import { longDay, shiftDay } from "../format";
import AmountPad from "../plan/AmountPad";
import { amountText } from "../plan/draft";
import Sheet from "../plan/Sheet";
import {
  CLOSED_GROUPS,
  REPEAT_NAMES,
  WEEKDAY_NAMES,
  groupTitle,
  hintChips,
  isoWeekday,
  overBy,
  ruleDays,
} from "./records";
import { amount, isoDay } from "./view";

const MAX_AHEAD_DAYS = 366; // как на сервере: не дальше чем через год
const REPEATS: Repeat[] = ["once", "daily", "weekdays", "monthly"];
const ORDER = ["UZS", "USD", "RUB"];
// поля с ошибкой под собой; остальные ошибки — над кнопкой
const FIELDS = [
  "currency",
  "group",
  "subcategory",
  "amount",
  "name",
  "repeat",
  "weekdays",
  "date",
];
const FIELD = "rounded-xl bg-section px-3 py-2 text-base text-text";

interface Props {
  api: Api;
  boot: Bootstrap;
  data: Forecast;
  day: number; // выбранный день — дата новой записи
  record: CalendarRecord | null; // null — новая запись
  onSaved: (fresh: Forecast) => void;
  onClose: () => void;
}

/** Валюты карт: UZS, USD, RUB, остальные по алфавиту; плюс валюта правки. */
function cardCurrencies(boot: Bootstrap, extra: string | undefined): string[] {
  const codes = new Set(boot.sources.map((source) => source.currency));
  if (extra) codes.add(extra);
  if (codes.size === 0) codes.add("UZS");
  const rest = [...codes].filter((code) => !ORDER.includes(code)).sort();
  return [...ORDER.filter((code) => codes.has(code)), ...rest];
}

function chip(on: boolean): string {
  return `rounded-full px-3 py-1.5 text-sm ${
    on ? "bg-button text-button-text" : "bg-section"
  }`;
}

function segment(on: boolean): string {
  return `rounded-lg px-1 py-1.5 text-sm font-medium ${
    on ? "bg-bg shadow-sm" : "text-hint"
  }`;
}

function FieldError({ text }: { text: string | undefined }) {
  return text ? <p className="text-sm text-danger">{text}</p> : null;
}

/** Окно записи календаря: статья, сумма с подсказками, название, повтор, дата. */
export default function RecordSheet({
  api,
  boot,
  data,
  day,
  record,
  onSaved,
  onClose,
}: Props) {
  const today = data.today;
  const end = data.end ?? today;
  const currencies = cardCurrencies(boot, record?.currency);
  const groups = boot.groups.filter(
    (item) => !CLOSED_GROUPS.includes(item.name),
  );
  const firstDate = record?.date ?? isoDay(today, day);
  const [currency, setCurrency] = useState(
    record?.currency ?? currencies[0] ?? "UZS",
  );
  const [group, setGroup] = useState(record?.group ?? "");
  const [subcategory, setSubcategory] = useState(record?.subcategory ?? "");
  const [text, setText] = useState(
    record ? amountText(record.amount, record.currency !== "UZS") : "",
  );
  const [name, setName] = useState(record?.name ?? "");
  const [repeat, setRepeat] = useState<Repeat>(record?.repeat ?? "once");
  const [weekdays, setWeekdays] = useState<number[]>(
    record?.weekdays.length ? record.weekdays : [isoWeekday(firstDate)],
  );
  const [date, setDate] = useState(firstDate);
  const [entryId] = useState(() => crypto.randomUUID());
  const [busy, setBusy] = useState(false);
  const [confirming, setConfirming] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [fields, setFields] = useState<Record<string, string>>({});
  const inFlight = useRef(false); // двойной тап — один запрос

  const chosen = groups.find((item) => item.name === group);
  const article = data.articles.find(
    (item) => item.subcategory === subcategory && item.currency === currency,
  );
  const value = amountValue(text);
  const days = ruleDays(repeat, weekdays, date, today, end);
  const before =
    record?.subcategory === subcategory && record.currency === currency
      ? record.booked
      : 0;
  const excess =
    subcategory && value > 0 ? overBy(article, before, days.length * value) : 0;
  const kept = record !== null && repeat !== "once" && date === record.date;
  const latest = shiftDay(today, MAX_AHEAD_DAYS);
  const dateOk = kept || (date >= today && date <= latest);
  const valid =
    group !== "" &&
    subcategory !== "" &&
    value > 0 &&
    dateOk &&
    (repeat !== "weekdays" || weekdays.length > 0);

  function fail(reason: unknown) {
    inFlight.current = false;
    setBusy(false);
    setConfirming(false);
    if (reason instanceof ApiError) {
      setFields(reason.fields);
      const underFields = FIELDS.some((field) => reason.fields[field]);
      setError(underFields ? null : reason.message);
    } else {
      setError("Не получилось сохранить — попробуйте ещё раз");
    }
  }

  function send(call: () => Promise<Forecast>) {
    if (inFlight.current) return;
    inFlight.current = true;
    setBusy(true);
    setError(null);
    setFields({});
    call().then(onSaved, fail);
  }

  function save() {
    const input: RecordInput = {
      date,
      repeat,
      weekdays:
        repeat === "weekdays" ? [...weekdays].sort((a, b) => a - b) : [],
      group,
      subcategory,
      currency,
      amount: apiAmount(text),
      name: name.trim(),
    };
    send(() =>
      record
        ? api.updateRecord(record.id, input)
        : api.addRecord({ ...input, entry_id: entryId }),
    );
  }

  function remove() {
    if (!record) return;
    if (!confirming) {
      setConfirming(true);
      return;
    }
    send(() => api.deleteRecord(record.id));
  }

  function toggleDay(number: number) {
    setWeekdays((current) =>
      current.includes(number)
        ? current.filter((item) => item !== number)
        : [...current, number],
    );
  }

  return (
    <Sheet
      title={record ? "Запись" : `Запись на ${longDay(date)}`}
      onClose={onClose}
    >
      <div className="flex items-center justify-between gap-2">
        <span className="text-sm text-hint">Статья</span>
        {currencies.length > 1 && (
          <div
            role="radiogroup"
            aria-label="Валюта"
            className="grid auto-cols-fr grid-flow-col gap-1 rounded-xl bg-section p-1"
          >
            {currencies.map((code) => (
              <button
                key={code}
                type="button"
                role="radio"
                aria-checked={currency === code}
                className={segment(currency === code)}
                onClick={() => {
                  setCurrency(code);
                  setText("");
                }}
              >
                {code}
              </button>
            ))}
          </div>
        )}
      </div>
      <FieldError text={fields.currency} />
      <div className="flex flex-wrap gap-1.5" role="group" aria-label="Группа">
        {groups.map((item) => (
          <button
            key={item.name}
            type="button"
            aria-pressed={group === item.name}
            className={chip(group === item.name)}
            onClick={() => {
              setGroup(item.name);
              setSubcategory("");
            }}
          >
            {`${item.emoji} ${item.title}`}
          </button>
        ))}
      </div>
      <FieldError text={fields.group} />
      {chosen && (
        <div
          className="flex flex-wrap gap-1.5"
          role="group"
          aria-label="Подкатегория"
        >
          {chosen.subcategories.map((item) => (
            <button
              key={item.name}
              type="button"
              aria-pressed={subcategory === item.name}
              className={chip(subcategory === item.name)}
              onClick={() => setSubcategory(item.name)}
            >
              {item.name}
            </button>
          ))}
        </div>
      )}
      <FieldError text={fields.subcategory} />
      {subcategory && (
        <p className="text-sm text-hint">
          {article && article.plan > 0
            ? `В статье осталось ${amount(article.rest, currency)} из ${amount(article.plan, currency)}`
            : "Статьи нет в плане месяца"}
        </p>
      )}
      {subcategory && (
        <div className="flex flex-wrap gap-1.5">
          {hintChips(data.hints[`${subcategory}|${currency}`], repeat).map(
            (hint) => (
              <button
                key={hint.label}
                type="button"
                className={chip(false)}
                onClick={() =>
                  setText(amountText(hint.value, currency !== "UZS"))
                }
              >
                {hint.label}
              </button>
            ),
          )}
        </div>
      )}
      <AmountPad text={text} currency={currency} onChange={setText} />
      <FieldError text={fields.amount} />
      <label className="flex flex-col gap-1 text-sm text-hint">
        Название
        <input
          className={FIELD}
          value={name}
          maxLength={60}
          placeholder={subcategory || "Необязательно"}
          onChange={(change) => setName(change.target.value)}
        />
      </label>
      <FieldError text={fields.name} />
      <span className="text-sm text-hint">Повтор</span>
      <div
        role="radiogroup"
        aria-label="Повтор"
        className="grid grid-cols-4 gap-1 rounded-xl bg-section p-1"
      >
        {REPEATS.map((item) => (
          <button
            key={item}
            type="button"
            role="radio"
            aria-checked={repeat === item}
            className={segment(repeat === item)}
            onClick={() => setRepeat(item)}
          >
            {REPEAT_NAMES[item]}
          </button>
        ))}
      </div>
      <FieldError text={fields.repeat} />
      {repeat === "weekdays" && (
        <div
          className="grid grid-cols-7 gap-1"
          role="group"
          aria-label="Дни недели"
        >
          {WEEKDAY_NAMES.map((label, index) => (
            <button
              key={label}
              type="button"
              aria-pressed={weekdays.includes(index + 1)}
              className={chip(weekdays.includes(index + 1))}
              onClick={() => toggleDay(index + 1)}
            >
              {label}
            </button>
          ))}
        </div>
      )}
      <FieldError text={fields.weekdays} />
      <label className="flex flex-col gap-1 text-sm text-hint">
        {repeat === "once" ? "Дата" : "Начало"}
        <input
          className={FIELD}
          type="date"
          min={kept ? record?.date : today}
          max={latest}
          value={date}
          onChange={(change) => {
            if (change.target.value) setDate(change.target.value);
          }}
        />
      </label>
      <FieldError text={fields.date} />
      {excess > 0 && (
        <p className="rounded-xl bg-warn/20 px-3 py-2 text-sm">
          {`⚠️ План статьи «${groupTitle(group)} / ${subcategory}» будет превышен на ${amount(excess, currency)}`}
        </p>
      )}
      {error && (
        <p className="text-sm text-danger" role="alert">
          {error}
        </p>
      )}
      <button
        type="button"
        disabled={!valid || busy}
        className="h-12 rounded-xl bg-button font-semibold text-button-text disabled:opacity-50"
        onClick={save}
      >
        {record ? "Сохранить" : "Запланировать"}
      </button>
      {record && (
        <button
          type="button"
          disabled={busy}
          className={
            confirming
              ? "h-12 rounded-xl bg-danger font-semibold text-white disabled:opacity-50"
              : "text-danger disabled:opacity-50"
          }
          onClick={remove}
        >
          {confirming ? "Удалить насовсем" : "Удалить запись"}
        </button>
      )}
    </Sheet>
  );
}
```
