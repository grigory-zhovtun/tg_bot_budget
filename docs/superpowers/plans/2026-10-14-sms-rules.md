# Разбор банковских SMS правилами — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SMS Капиталбанка и UZCARD, вставленные в чат, бот разбирает шаблонами без ИИ: карта, дата, сумма, остаток — из текста, категория — из памяти по сумме и истории магазинов; ИИ одним запросом подсказывает только новые магазины. Сомнительные строки помечены 🆕/❓, их можно проверить кнопками. Незнакомый текст, как раньше, разбирает Gemini.

**Architecture:** Чистый модуль `app/sms.py` делит текст на SMS по шаблонам (или возвращает `None` — тогда ИИ). Чистый модуль `app/sms_rows.py` решает класс операции, категорию, пометку, пары «свой перевод / обмен» и отдаёт позиции в формате ответа ИИ, чтобы строку собирал тот же `build_row`. Обработчик `app/handlers/sms.py` берёт историю из кэша `GeminiService`, отбрасывает уже записанные SMS, спрашивает ИИ о новых магазинах и отдаёт строки в `save_rows`, которая показывает пометки и кнопку «🔎 Проверить». Проверка — тот же диалог, что `/fix`, с «✓ Верно» и очередью.

**Tech Stack:** Python 3.12, python-telegram-bot 22.8, Pydantic 2, gspread, pytest (asyncio auto).

**Spec:** `docs/superpowers/specs/2026-10-14-sms-rules-design.md`

## Global Constraints

- Репозиторий публичный: в коде, тестах и документах — только условные магазины, суммы и остатки; номера карт — только те, что уже есть в тестах (`VISA 9090 UZS`, `UZCARD 5656 UZS`, `VISA 3434 USD`). Выгрузка SMS владельца, 50 SMS из чата и дампы таблицы лежат только в scratchpad сессии и в git не попадают.
- Секреты не читаем и не вводим: `.env` не открываем.
- Python: type hints на всех сигнатурах, black + ruff (строка 88); перед коммитом в venv проекта: `ruff check . && black --check . && pytest -q`.
- Числа из спеки: подсказка ИИ — 30 секунд (`SUGGEST_SECONDS`); память по сумме — 60 дней (`MEMORY_DAYS`); пара — 10 минут (`PAIR_MINUTES`); своя комиссия — до 1 % (`OWN_FEE_SHARE`); обмен — ± 10 % по курсу таблицы (`FX_SHARE`); статья большинства — от 80 % строк (`DOMINANT_SHARE`); отпечатков — до 1000 (`SEEN_LIMIT`); кофе без магазина — до 60 000 сумов (`ANON_COFFEE_LIMIT`), доллары наличными 650 — квартплата (`RENT_CASH_USD`); оба порога — константы импорта выписок.
- Тексты для владельца — ровно как в шагах плана (сводка, проверка, ошибки), по-русски.
- Логи без текстов SMS, сумм и названий магазинов.

## Review Focus

1. **Реальная SMS чуть иначе образца** — лишние или неразрывные пробелы, другой апостроф, SMS разорвана переносом, приписка владельца. Пишем только то, что узнано целиком, остальное — ИИ (тесты `test_unusual_spaces_are_ignored`, `test_anything_unknown_goes_to_ai` в Task 2, `test_sms_with_own_words_goes_to_ai` в Task 6).
2. **Вставка «сверху новые»**: несколько SMS одной карты и SMS одной минуты — строки по времени, остаток в «Проверку» из самой поздней (`test_newest_first_paste_is_written_in_time_order_with_the_latest_balance`, `test_sms_of_one_minute_keep_the_bank_order` в Task 3).
3. **ИИ медленный или правила упали** — строки всё равно пишутся, а при ошибке в правилах текст разбирает ИИ (`test_slow_ai_does_not_stop_the_write`, `test_rules_failure_falls_back_to_ai` в Task 6).
4. **Кнопки проверки старой записи после новой** ничего не трогают (`test_check_buttons_of_an_older_write_are_stale` в Task 5).
5. **Повтор SMS** внутри вставки и в следующей вставке пишется один раз, сводка показывает, где он уже есть (`test_same_sms_twice_in_one_message_is_written_once`, `test_sms_written_before_is_not_written_again` в Task 6).

```python
_GENERIC = re.compile(
    r"^(без мерчанта|humo, тсп|выравнивание|перевод|конвертация|снятие|внесение|"
    r"входящий|списание|комиссия|остаток|наличные|←|→|ai$|\?\?)",
    re.IGNORECASE,
)
# Оплата через агрегатор без названия магазина: в SMS видно только Payme, Click, QR
ANONYMOUS_PAYMENT = re.compile(
    r"PAYME OPLATA|CLICK OPLATA|PAYME EDIN QR|PAYME QR\b.*|(?:AO|OOO) CLICK\b.*"
    r"|.* to QRonlin.*",
    re.IGNORECASE,
)
```

`merchant_key` целиком:

```python
def merchant_key(comment: str) -> str | None:
    """«AI: Ip Ooo Anglesey Food (Сингапур); ≈ 3 USD» → «IP OOO ANGLESEY FOOD».

    Хвост «>город» из SMS отбрасывается: YANDEX.GO>YUNUSOBOD — тот же YANDEX.GO.
    Оплата через агрегатор (PAYME OPLATA, QR) — не магазин.
    """
    text = re.sub(r"^(AI|SMS):\s*", "", (comment or "").strip(), flags=re.IGNORECASE)
    if not text or _GENERIC.match(text):
        return None
    text = re.split(r"[;(,>]| ≈ ", text, maxsplit=1)[0].strip()
    if ANONYMOUS_PAYMENT.fullmatch(text):
        return None
    text = re.sub(r"\s+", " ", text).upper()[:40]
    return text if len(text) >= 3 and not text.isdigit() else None
```

`MerchantBook.__init__` целиком:

```python
    def __init__(self, entries: Iterable[tuple[str, str, str]]) -> None:
        newest: dict[str, tuple[str, str]] = {}  # самая свежая строка магазина
        counts: dict[str, Counter[tuple[str, str]]] = defaultdict(Counter)
        self.first: dict[str, set[tuple[str, str]]] = defaultdict(set)
        for category, subcategory, comment in reversed(list(entries)):
            key = merchant_key(comment)
            if not key or not category or not subcategory:
                continue
            target = (category, subcategory)
            core = merchant_core(key)
            keys = [key, "core:" + core] if core else [key]
            if core:
                self.first[core.split()[0]].add(target)
            for name in keys:
                newest.setdefault(name, target)
                if category != FALLBACK_CATEGORY:  # «РАЗНОЕ» — не решение владельца
                    counts[name][target] += 1
        best: dict[str, tuple[str, str]] = {}
        # Магазин с разными статьями решён, если в одну попало 80 % его строк;
        # иначе (маркетплейс: продукты, химия, одежда) история его не решает
        self.mixed: set[str] = set()
        for name, target in newest.items():
            if not counts[name]:
                best[name] = target  # только «РАЗНОЕ»
                continue
            top, rows = counts[name].most_common(1)[0]
            best[name] = top
            if rows < DOMINANT_SHARE * counts[name].total():
                self.mixed.add(name)
        self.exact = {k: v for k, v in best.items() if not k.startswith("core:")}
        self.core = {k[5:]: v for k, v in best.items() if k.startswith("core:")}
```

```python
"""Банковские SMS Капиталбанка и UZCARD → операции по шаблонам, без ИИ.

Текст разбирается, только если каждая его строка целиком состоит из SMS
известных видов; иначе parse_sms возвращает None и текст разбирает ИИ, как раньше.
"""

import re
from dataclasses import dataclass, field
from datetime import datetime
from enum import StrEnum

from app.domain import MONTHS


class Kind(StrEnum):
    """Что за операция по виду SMS — до разбора описания."""

    PAYMENT = "payment"  # покупка, оплата, operacija
    OUTGOING = "outgoing"  # перевод с карты, списание со счёта
    CASH_OUT = "cash_out"  # снятие наличных
    INCOMING = "incoming"  # зачисление на карту
    CASH_IN = "cash_in"  # внесение наличных


INCOMING_KINDS = frozenset({Kind.INCOMING, Kind.CASH_IN})

# почему SMS не пишется в таблицу
CODE = "код подтверждения"
DECLINED = "отказ банка"
WRONG_PIN = "неверный PIN"


@dataclass(frozen=True)
class Sms:
    """Одна операция из SMS так, как её написал банк."""

    text: str  # SMS целиком — по нему отпечаток повторов
    card: str  # последние 4 цифры карты
    kind: Kind
    description: str  # магазин, место или «откуда 2 куда»; у счёта — пусто
    amount: float  # без знака
    currency: str
    at: datetime  # местное время операции
    balance: float | None = None
    balance_currency: str | None = None
    cancelled: bool = False  # отмена покупки: деньги вернулись

    @property
    def incoming(self) -> bool:
        """Деньги пришли на карту: зачисление или отмена списания."""
        return self.cancelled or self.kind in INCOMING_KINDS


@dataclass(frozen=True)
class SmsBatch:
    """Сообщение из SMS: операции и пропущенные SMS (коды, отказы)."""

    operations: list[Sms] = field(default_factory=list)
    skipped: list[str] = field(default_factory=list)


_AMOUNT = r"\d+(?:\.\d+)?"
_MONTHS = [name.upper() for name in MONTHS]
_KAPITAL_KINDS = {
    "Xarid/Pokupka": Kind.PAYMENT,
    "operacija": Kind.PAYMENT,
    "vznos": Kind.INCOMING,
    "Naqd yechish/Snyatie nalichnih": Kind.CASH_OUT,
    "Kirim/Vnesenie nalichnih": Kind.CASH_IN,
}
KAPITAL_CARD = re.compile(
    r"(?:(?P<cancel>Avtorizacija otmenena\. Avtorizacija bekor qilindi\.)"
    r"|(?P<declined>Hisobda mablag. yetarli emas\. Nedostatochno sredstv\.))? ?"
    r"Karta \*(?P<card>\d{4})\. "
    rf"(?P<kind>{'|'.join(map(re.escape, _KAPITAL_KINDS))}) "
    rf'"(?P<desc>[^"]*)", (?P<sign>[+-]?)(?P<amount>{_AMOUNT}), (?P<cur>[A-Z]{{3}}), '
    r'"(?P<day>\d{2})-(?P<month>\d{2})-(?P<year>\d{4}|\d{2}) (?P<time>\d{2}:\d{2})"\. '
    rf"Dostupno: (?P<balance>-?{_AMOUNT}), (?P<bcur>[A-Z]{{3}})\."
)
KAPITAL_P2P = re.compile(
    r"(?P<kind>Snyatiye|Popolneniye), "
    r"(?P<day>\d{2})\.(?P<month>\d{2})\.(?P<year>\d{2}) v (?P<time>\d{2}:\d{2})\. "
    r"Karta \(\*(?P<card>\d{4})\)\. "
    rf"Summa: (?P<amount>{_AMOUNT}) (?P<cur>[A-Z]{{3}})\. (?P<desc>.+?)\. "
    rf"Dostupno: (?P<balance>-?{_AMOUNT}) (?P<bcur>[A-Z]{{3}})\.?"
)
KAPITAL_ACCOUNT = re.compile(
    r"Schet po karte \*(?P<card>\d{4}) (?P<kind>spisan|popolnen) na summu "
    rf"-?(?P<amount>{_AMOUNT}) (?P<cur>[A-Z]{{3}})\. "
    r"(?P<day>\d{2})-(?P<month>[A-Z]{3})-(?P<year>\d{4}|\d{2}) (?P<time>\d{2}:\d{2})"
)

    r"|Kapitalbank: data plateja .*?Kod podtverjdeniya(?: oplati)?: \d+"

INCORRECT_PIN = re.compile(r"INCORRECT PIN .*")


def _when(match: re.Match[str], month: int) -> datetime:
    """Время операции: год бывает из двух цифр."""
    year = int(match["year"]) + (2000 if len(match["year"]) == 2 else 0)
    hours, minutes = match["time"].split(":")
    return datetime(year, month, int(match["day"]), int(hours), int(minutes))


def _kapital_card(match: re.Match[str]) -> Sms | str | None:
    if match["declined"]:
        return DECLINED
    kind = _KAPITAL_KINDS[match["kind"]]
    sign = match["sign"]
    if sign and (sign == "+") != (kind in INCOMING_KINDS):
        return None  # знак не совпал с видом — смысл SMS не тот, что мы знаем
    if match["cancel"] and kind != Kind.PAYMENT:
        return None
    return Sms(
        text=match[0],
        card=match["card"],
        kind=kind,
        description=match["desc"].strip(),
        amount=float(match["amount"]),
        currency=match["cur"],
        at=_when(match, int(match["month"])),
        balance=float(match["balance"]),
        balance_currency=match["bcur"],
        cancelled=bool(match["cancel"]),
    )


def _kapital_p2p(match: re.Match[str]) -> Sms:
    return Sms(
        text=match[0],
        card=match["card"],
        kind=Kind.OUTGOING if match["kind"] == "Snyatiye" else Kind.INCOMING,
        description=match["desc"].strip(),
        amount=float(match["amount"]),
        currency=match["cur"],
        at=_when(match, int(match["month"])),
        balance=float(match["balance"]),
        balance_currency=match["bcur"],
    )


def _kapital_account(match: re.Match[str]) -> Sms | None:
    if match["month"] not in _MONTHS:
        return None
    return Sms(
        text=match[0],
        card=match["card"],
        kind=Kind.OUTGOING if match["kind"] == "spisan" else Kind.INCOMING,
        description="",
        amount=float(match["amount"]),
        currency=match["cur"],
        at=_when(match, _MONTHS.index(match["month"]) + 1),
    )


def _uzcard(match: re.Match[str]) -> Sms | None:
    kind = _UZCARD_KINDS[re.sub(f"[{_APOSTROPHES}]", "'", match["kind"])]
    if match["cancel"] and kind != Kind.PAYMENT:
        return None
    return Sms(
        text=match[0],
        card=match["card"],
        kind=kind,
        description=match["desc"].strip(),
        amount=float(match["amount"]),
        currency="UZS",
        at=_when(match, int(match["month"])),
        balance=float(match["balance"]),
        balance_currency="UZS",
        cancelled=bool(match["cancel"]),
    )


_TEMPLATES = (
    (KAPITAL_CARD, _kapital_card),
    (KAPITAL_P2P, _kapital_p2p),
    (KAPITAL_ACCOUNT, _kapital_account),
    (UZCARD, _uzcard),
    (CODES, lambda _: CODE),
    (INCORRECT_PIN, lambda _: WRONG_PIN),
)


def _read(line: str, start: int) -> tuple[Sms | str, int] | None:
    """SMS с позиции start: операция или причина пропуска и где SMS кончилась."""
    for pattern, convert in _TEMPLATES:
        match = pattern.match(line, start)
        if match is None:
            continue
        try:
            result = convert(match)
        except ValueError:  # 31.02 и прочие невозможные даты
            return None
        return None if result is None else (result, match.end())
    return None


def parse_sms(text: str) -> SmsBatch | None:
    """Текст из SMS → операции; None — если хоть что-то в тексте не узнано."""
    batch = SmsBatch()
    for raw in text.splitlines():
        line = re.sub(r"\s+", " ", raw).strip()
        position = 0
        while position < len(line):
            found = _read(line, position)
            if found is None:
                return None
            result, position = found
            if isinstance(result, Sms):
                batch.operations.append(result)
            else:
                batch.skipped.append(result)
            while position < len(line) and line[position] == " ":
                position += 1
    return batch if batch.operations or batch.skipped else None
```

```python
"""SMS → позиции листа fact: класс операции, категория, пометка проверки, пары.

Чистые функции без сети: историю магазинов, память по сумме и подсказки ИИ
передаёт обработчик чата (app/handlers/sms.py).
"""

import re
from collections import defaultdict
from dataclasses import dataclass
from datetime import date, datetime, timedelta
from enum import StrEnum
from typing import Any

from app.domain import (
    ANONYMOUS_PAYMENT,
    FALLBACK_CATEGORY,
    INCOME_GROUP,
    MerchantBook,
    Rates,
    Skipped,
    currency_of,
    merchant_key,
    parse_number,
)
from app.sms import Kind, Sms
from app.statements import (
    ANON_COFFEE_LIMIT,
    COFFEE,
    FX,
    MISC,
    RENT,
    RENT_CASH_USD,
    SERIAL_ZERO,
    TRANSFERS,
    short,
)

NEW = "🆕"  # новый магазин: категорию подсказал ИИ
CHECK = "❓"  # операция без магазина: категория временная
MEMORY_DAYS = 60
PAIR_MINUTES = 10
OWN_FEE_SHARE = 0.01  # свой перевод: списание больше зачисления не больше чем на 1 %
FX_SHARE = 0.10  # обмен: суммы по курсу таблицы расходятся не больше чем на 10 %

# «VISA MC UZS 2 UZCARD OB», «WD VISAUZS KB to HUMO» — перевод с карты на карту;
# «VSMCUZSKB to QRonlin» — оплата по QR, её узнаёт ANONYMOUS_PAYMENT
CARD_TO_CARD = re.compile(
    r"(?:WD )?(?:VISA\w*|VSMC\w*|MC|HUMO\w*|UZCARD\w*|ACCOUNT)\b.*? (?:2|to|TO) (?!QR)"
)
VIA_BANK_APP = re.compile(
    r"P2P|NA KARTU|FRB KAPITAL"
)  # переводы и платежи в приложении


class Purpose(StrEnum):
    """Класс операции: от него зависят направление, категория и пометка."""

    MERCHANT = "merchant"  # покупка у магазина
    ANONYMOUS = "anonymous"  # оплата без магазина: Payme, Click, QR
    TRANSFER = "transfer"  # перевод с карты, списание со счёта
    CASH_OUT = "cash_out"
    INCOMING = "incoming"
    CASH_IN = "cash_in"


_BY_KIND = {
    Kind.INCOMING: Purpose.INCOMING,
    Kind.CASH_IN: Purpose.CASH_IN,
    Kind.CASH_OUT: Purpose.CASH_OUT,
    Kind.OUTGOING: Purpose.TRANSFER,
}


def purpose(sms: Sms) -> Purpose:
    """Сначала вид SMS, потом описание. Отмена — класс отменённой операции."""
    if sms.kind in _BY_KIND:
        return _BY_KIND[sms.kind]
    text = sms.description
    if CARD_TO_CARD.match(text) or VIA_BANK_APP.search(text):
        # отменённый перевод с карты — деньги вернулись на карту
        return Purpose.INCOMING if sms.cancelled else Purpose.TRANSFER
    if not text or ANONYMOUS_PAYMENT.fullmatch(text):
        return Purpose.ANONYMOUS
    return Purpose.MERCHANT


def place(description: str) -> str:
    """«VISA MC UZS 2 UZCARD OB>Tashkent UZ» → «VISA MC UZS 2 UZCARD OB»."""
    return description.split(">")[0].strip()


def card_source(card: str, sources: list[str]) -> str | None:
    """Карта из листа system по четырём цифрам; нет такой или их несколько — None."""
    found = [source for source in sources if card in source.split()]
    return found[0] if len(found) == 1 else None


def _decided(target: tuple[str, str] | None) -> tuple[str, str] | None:
    """Решение владельца: не «РАЗНОЕ» и не доход — покупка доходом не бывает."""
    if target is None or target[0] in (FALLBACK_CATEGORY, INCOME_GROUP):
        return None
    return target


def _cell_day(value: Any) -> date | None:
    """Дата из fact: «14.10.2026» или серийный номер Google Sheets."""
    if isinstance(value, int | float) and not isinstance(value, bool):
        return SERIAL_ZERO + timedelta(days=int(value))
    try:
        return datetime.strptime(str(value).strip(), "%d.%m.%Y").date()
    except ValueError:
        return None


def _cell_amount(value: Any) -> float | None:
    """Сумма D со знаком: «65 000,00», «-1 000» или число."""
    if isinstance(value, int | float) and not isinstance(value, bool):
        return float(value)
    number = parse_number(value)
    if number is None:
        return None
    return -number if str(value).strip().startswith(("-", "−")) else number


def _nameless(comment: str) -> bool:
    """Строка без названия магазина: ввод из Mini App, QR, «без мерчанта»."""
    text = re.sub(r"^(AI|SMS):\s*", "", comment.strip(), flags=re.IGNORECASE)
    text = text.split(";")[0].strip()
    return (
        text.lower() in ("", "ai")
        or "без мерчанта" in text.lower()
        or bool(ANONYMOUS_PAYMENT.fullmatch(text))
    )


@dataclass(frozen=True)
class AmountMemory:
    """Категории расходов fact за 60 дней по (карта, магазин, сумма).

    Магазин "" — строки без названия: так узнаётся кофе по QR за ту же сумму.
    """

    targets: dict[tuple[str, str, float], frozenset[tuple[str, str]]]

    @classmethod
    def from_sheet(cls, rows: list[list[Any]], today: date) -> "AmountMemory":
        """Лист fact как есть (первая строка — заголовок)."""
        found: dict[tuple[str, str, float], set[tuple[str, str]]] = defaultdict(set)
        start = today - timedelta(days=MEMORY_DAYS)
        for row in rows[1:]:
            cells = [*row[:8], *[""] * (8 - len(row[:8]))]
            day, amount = _cell_day(cells[0]), _cell_amount(cells[3])
            target = (str(cells[1]).strip(), str(cells[2]).strip())
            if day is None or amount is None or amount <= 0:
                continue
            if not start <= day <= today or not target[1] or _decided(target) is None:
                continue
            comment = str(cells[5])
            name = "" if _nameless(comment) else merchant_key(comment)
            if name is None:
                continue  # перевод, снятие и прочие служебные строки
            found[(str(cells[7]).strip(), name, round(amount, 2))].add(target)
        return cls({key: frozenset(value) for key, value in found.items()})

    def find(self, source: str, name: str, amount: float) -> tuple[str, str] | None:
        """Категория, если у всех таких строк она одна; name "" — без магазина."""
        targets = self.targets.get((source, name, round(amount, 2)), frozenset())
        return next(iter(targets)) if len(targets) == 1 else None


def _merchant_target(
    sms: Sms, source: str, book: MerchantBook, memory: AmountMemory
) -> tuple[str, str] | None:
    """Категория покупки: память по сумме у этого магазина, иначе его история."""
    name = merchant_key(sms.description)
    if name and sms.currency == currency_of(source):
        if remembered := memory.find(source, name, sms.amount):
            return remembered
    return _decided(book.find(sms.description))


def new_merchants(
    operations: list[Sms], sources: list[str], book: MerchantBook, memory: AmountMemory
) -> list[str]:
    """Магазины, которых нет ни в памяти, ни в истории: о них спросим ИИ."""
    names: list[str] = []
    for sms in operations:
        source = card_source(sms.card, sources)
        if purpose(sms) != Purpose.MERCHANT or source is None:
            continue
        if _merchant_target(sms, source, book, memory) is None:
            name = place(sms.description)
            if name and name not in names:
                names.append(name)
    return names


@dataclass(frozen=True)
class SmsRow:
    """Позиция для записи: ответ «как от ИИ» для build_row и пометка проверки."""

    item: dict[str, Any]
    flag: str | None  # NEW, CHECK или None
    sms: Sms | None  # None — строка комиссии своего перевода


@dataclass(frozen=True)
class Pair:
    """Вторая сторона своего перевода или обмена в том же сообщении."""

    other: Sms
    other_source: str
    kind: str  # "own" — перевод между своими картами, "fx" — обмен валюты


def _item(
    sms: Sms,
    source: str,
    target: tuple[str, str],
    comment: str,
    direction: str,
    balance: float | None,
    amount: float | None = None,
) -> dict[str, Any]:
    return {
        "amount": sms.amount if amount is None else amount,
        "currency": sms.currency,
        "date": sms.at.strftime("%d.%m.%Y"),
        "category": target[0],
        "subcategory": target[1],
        "comment": comment,
        "source": source,
        "card_identifier": sms.card,
        "direction": direction,
        "balance": balance,
    }


def _amounts_match(debit: Sms, credit: Sms, rates: Rates) -> bool:
    if debit.currency == credit.currency:
        return credit.amount <= debit.amount <= credit.amount * (1 + OWN_FEE_SHARE)
    converted = rates.convert(debit.amount, debit.currency, credit.currency)
    return (
        converted is not None
        and abs(converted - credit.amount) <= FX_SHARE * credit.amount
    )


def find_pairs(
    operations: list[Sms], cards: list[str | None], rates: Rates
) -> dict[int, Pair]:
    """Списание с одной своей карты и зачисление на другую за 10 минут — пара.

    Каждая SMS — не больше чем в одной паре, ближайшее по времени зачисление первым.
    """
    debits = [
        i
        for i, sms in enumerate(operations)
        if cards[i] and purpose(sms) == Purpose.TRANSFER
    ]
    credits = [
        i
        for i, sms in enumerate(operations)
        if cards[i] and purpose(sms) == Purpose.INCOMING
    ]
    pairs: dict[int, Pair] = {}
    for i in sorted(debits, key=lambda index: operations[index].at):
        best: tuple[float, int] | None = None
        for j in credits:
            if j in pairs or cards[j] == cards[i]:
                continue
            gap = abs((operations[j].at - operations[i].at).total_seconds())
            if gap > PAIR_MINUTES * 60:
                continue
            if not _amounts_match(operations[i], operations[j], rates):
                continue
            if best is None or gap < best[0]:
                best = (gap, j)
        if best is None:
            continue
        j = best[1]
        debit_card, credit_card = cards[i] or "", cards[j] or ""
        kind = "fx" if currency_of(debit_card) != currency_of(credit_card) else "own"
        pairs[i] = Pair(operations[j], credit_card, kind)
        pairs[j] = Pair(operations[i], debit_card, kind)
    return pairs


def _pair_rows(
    sms: Sms, source: str, pair: Pair, balance: float | None
) -> list[SmsRow]:
    """Строки своего перевода или обмена — как в импорте выписок."""
    label = "конвертация" if pair.kind == "fx" else "перевод"
    arrow = "←" if sms.incoming else "→"
    comment = f"{label} {short(source)} {arrow} {short(pair.other_source)} (свой)"
    target = FX if pair.kind == "fx" else TRANSFERS
    direction = "transfer_in" if sms.incoming else "transfer_out"
    fee = 0.0
    if pair.kind == "own" and not sms.incoming:
        fee = round(sms.amount - pair.other.amount, 2)
    if fee < 0.01:
        return [
            SmsRow(_item(sms, source, target, comment, direction, balance), None, sms)
        ]
    sent = _item(sms, source, target, comment, direction, balance, pair.other.amount)
    charge = _item(
        sms, source, MISC, "комиссия за перевод на свою карту", "expense", None, fee
    )
    return [SmsRow(sent, None, sms), SmsRow(charge, None, None)]


def _decide(
    sms: Sms,
    source: str,
    book: MerchantBook,
    memory: AmountMemory,
    suggestions: dict[str, tuple[str, str]],
    rates: Rates,
) -> tuple[tuple[str, str], str | None, str, str]:
    """Категория, пометка, комментарий и направление одной SMS."""
    kind = purpose(sms)
    where = place(sms.description)
    if kind == Purpose.INCOMING:
        what = where or "пополнение счёта"
        return TRANSFERS, CHECK, f"входящий перевод: {what}", "transfer_in"
    if kind == Purpose.CASH_IN:
        return TRANSFERS, CHECK, f"внесение наличных: {where}", "transfer_in"
    if kind == Purpose.CASH_OUT:
        comment = f"снятие наличных: {where}"
        if sms.currency == "USD":  # доллары в кассе банка — квартплата
            flag = None if sms.amount == RENT_CASH_USD else CHECK
            return RENT, flag, comment, "transfer_out"
        return MISC, CHECK, comment, "transfer_out"
    if kind == Purpose.TRANSFER:
        what = where or "списание со счёта"
        return MISC, CHECK, f"перевод: {what}", "transfer_out"
    direction = "refund" if sms.cancelled else "expense"
    if kind == Purpose.ANONYMOUS:
        comment = sms.description or "без мерчанта"
        if sms.currency == currency_of(source):
            if remembered := memory.find(source, "", sms.amount):
                return remembered, None, comment, direction
        in_sums = rates.convert(sms.amount, sms.currency, "UZS")
        small = in_sums is not None and in_sums <= ANON_COFFEE_LIMIT
        return (COFFEE if small else MISC), CHECK, comment, direction
    if known := _merchant_target(sms, source, book, memory):
        return known, None, sms.description, direction
    suggested = _decided(suggestions.get(where))
    return (suggested or MISC), NEW, sms.description, direction


def sms_rows(
    operations: list[Sms],
    sources: list[str],
    book: MerchantBook,
    memory: AmountMemory,
    suggestions: dict[str, tuple[str, str]],
    rates: Rates,
) -> tuple[list[SmsRow], list[Skipped]]:
    """SMS сообщения → позиции в порядке времени и то, что записать нельзя.

    Вставку из приложения «сверху новые» сначала разворачиваем: SMS одной минуты
    остаются в порядке банка. Остаток в «Проверку» — только у самой поздней SMS карты.
    """
    ops = list(operations)
    if len(ops) > 1 and ops[0].at > ops[-1].at:
        ops.reverse()
    order = sorted(range(len(ops)), key=lambda index: ops[index].at)
    cards = [card_source(sms.card, sources) for sms in ops]
    latest = {cards[i]: i for i in order if cards[i]}
    pairs = find_pairs(ops, cards, rates)
    rows: list[SmsRow] = []
    skipped: list[Skipped] = []
    for i in order:
        sms, source = ops[i], cards[i]
        if source is None:
            what = place(sms.description) or (
                "пополнение счёта" if sms.incoming else "списание со счёта"
            )
            skipped.append(
                Skipped(f"карта *{sms.card} не найдена в листе system", what)
            )
            continue
        own = latest[source] == i and sms.balance_currency == currency_of(source)
        balance = sms.balance if own else None
        if i in pairs:
            rows += _pair_rows(sms, source, pairs[i], balance)
            continue
        target, flag, comment, direction = _decide(
            sms, source, book, memory, suggestions, rates
        )
        rows.append(
            SmsRow(_item(sms, source, target, comment, direction, balance), flag, sms)
        )
    return rows, skipped
```

```python
def categories_menu(
    categories: list[str],
    with_actions: bool = False,
    custom: CustomIcons | None = None,
    check: int = 0,
) -> InlineKeyboardMarkup:
    """Группы; сразу после записи сверху — «Исправить» и «Отменить» для неё.

    check — сколько строк записи с пометкой 🆕/❓ ещё не проверено: над действиями
    тогда стоит «🔎 Проверить (N)».
    """
    rows = [
        list(row)
        for row in generate_categories_keyboard(categories, custom).inline_keyboard
    ]
    if with_actions:
        rows.insert(
            0,
            [
                action("✏️ Исправить запись", LAST_FIX, KeyboardButtonStyle.PRIMARY),
                action("↩️ Отменить запись", LAST_UNDO, KeyboardButtonStyle.DANGER),
            ],
        )
        if check:
            label = f"🔎 Проверить ({check})"
            rows.insert(0, [action(label, LAST_CHECK, KeyboardButtonStyle.PRIMARY)])
    return InlineKeyboardMarkup(rows)
```

```python
SEEN_TTL = 7 * 24 * 3600
MIN_SMS_LENGTH = 20  # короче — это ручной ввод вроде «48000 латте», повтор законен


def input_fingerprint(
    text: str | None, file_unique_id: str | None = None
) -> str | None:
    """Отпечаток SMS или файла: тот же текст или тот же файл Telegram — тот же ключ."""
    if file_unique_id:
        return f"file:{file_unique_id}"
    normalized = re.sub(r"\s+", " ", text or "").strip().lower()
    if len(normalized) < MIN_SMS_LENGTH:
        return None
    return "text:" + hashlib.sha256(normalized.encode()).hexdigest()[:16]


def seen_input(
    context: ContextTypes.DEFAULT_TYPE, fingerprint: str | None
) -> dict | None:
    """Запись о том, что этот вход уже записан в таблицу (не старше недели)."""
    if fingerprint is None:
        return None
    entry = context.user_data.get(SEEN_INPUTS, {}).get(fingerprint)
    if entry and time.time() - entry["at"] < SEEN_TTL:
        return entry
    return None
```

```python
"""/fix — поменять группу и подгруппу последней записи (AI ошибся с категорией).

Сценарий: /fix → [какую операцию, если их несколько] → группа → подгруппа.
Кнопки ссылаются на номера в списках справочника (callback_data ≤ 64 байт),
перед записью строка сверяется с таблицей, как в /undo.

Тот же диалог проверяет строки SMS с пометкой 🆕 или ❓: единственную — прямо в
меню под сводкой («inline»), несколько — по очереди отдельным сообщением

# user_data: {"write": снимок последней записи, "row": индекс строки, "category":
# группа; у проверки ещё "mode", а в очереди — "queue", "done", "fixed", "total"}

INLINE, QUEUE = "inline", "queue"

def describe(row: SheetRow) -> str:
    comment = row.comment.removeprefix("AI: ").strip()
    note = f" • {comment[:40]}" if comment else ""
    return f"{format_amount(row)}{note} • {row.category} ({row.subcategory}) • {row.source}"


def amount_for(row: SheetRow, category: str) -> float | None:
    """Сумма D в новой группе так, чтобы деньги шли в ту же сторону.

    Доход пишется плюсом, прочий приход — минусом, расход — плюсом. Приход
    между доходом и прочими статьями меняет знак; списание доходом стать
    не может — None.
    """
    was_income, now_income = row.category == INCOME_GROUP, category == INCOME_GROUP
    if was_income == now_income:
        return row.amount
    if now_income:
        return -row.amount if row.amount < 0 else None
    return -row.amount


def _grid(
    buttons: list[InlineKeyboardButton], per_row: int
) -> list[list[InlineKeyboardButton]]:
    return [buttons[i : i + per_row] for i in range(0, len(buttons), per_row)]


def _groups(
    categories: list[str], custom: CustomIcons | None
) -> list[list[InlineKeyboardButton]]:
    buttons = [
        group_button(name, f"fix:c:{index}", custom)
        for index, name in enumerate(categories)
    ]
    return _grid(buttons, 2)


def categories_keyboard(
    categories: list[str], custom: CustomIcons | None = None
) -> InlineKeyboardMarkup:
    return InlineKeyboardMarkup([*_groups(categories, custom), [CANCEL]])

    subcategories: list[str],
    icons: dict[str, str] | None = None,
    custom: CustomIcons | None = None,

    buttons = [
        subcategory_button(name, f"fix:s:{index}", icons, custom)
        for index, name in enumerate(subcategories)
    ]
    back = InlineKeyboardButton("⬅️ Назад", callback_data="fix:b")
    return InlineKeyboardMarkup([*_grid(buttons, 2), [back, CANCEL]])


def check_keyboard(
    categories: list[str], custom: CustomIcons | None, mode: str
) -> InlineKeyboardMarkup:
    """[✓ Верно], группы по две, внизу «↩️ Отменить запись» или «⏹ Хватит»."""
    if mode == INLINE:
        bottom = action("↩️ Отменить запись", LAST_UNDO, KeyboardButtonStyle.DANGER)
    else:
        bottom = InlineKeyboardButton("⏹ Хватит", callback_data="fix:x")
    ok = action("✓ Верно", "fix:ok", KeyboardButtonStyle.SUCCESS)
    return InlineKeyboardMarkup([[ok], *_groups(categories, custom), [bottom]])


def check_text(last: dict, index: int, prefix: str = "") -> str:
    """«🆕 OOO SHAVI CAFE • 48 000 UZS • VISA 9090 UZS» и что с категорией."""
    row: SheetRow = last["rows"][index]
    flag = last["checks"].get(index, "")
    guessed = row.category != FALLBACK_CATEGORY
    lead = "ИИ предлагает" if flag == NEW and guessed else "Записал как"
    question = "Верно?" if guessed else "Что это?"
    return (
        f"{prefix}{flag} {row_name(row)} • {format_amount(row)} • {row.source}\n"
        f"{lead}: {row.category} / {row.subcategory}. {question}"
    )


def rows_keyboard(rows: list[SheetRow]) -> InlineKeyboardMarkup:
    buttons = [
        [
            InlineKeyboardButton(
                f"{i + 1}) {format_amount(row)} • {row.subcategory}",
                callback_data=f"fix:r:{i}",
            )
        ]
        for i, row in enumerate(rows)
    ]
    return InlineKeyboardMarkup([*buttons, [CANCEL]])


def _snapshot(last: dict) -> tuple:
    """Какая запись сейчас последняя: кнопки старой записи не должны править новую."""
    return last["first"], tuple(last["rows"])


def _index(rest: list[str], items: list) -> int | None:
    """Номер из кнопки, если он ещё указывает на элемент списка."""
    if len(rest) == 1 and rest[0].isdigit() and int(rest[0]) < len(items):
        return int(rest[0])
    return None


async def _edit(
    query: CallbackQuery, text: str, markup: InlineKeyboardMarkup | None = None
) -> None:
    """Обновить сообщение /fix; повторное нажатие той же кнопки — не ошибка."""
    try:
        await query.edit_message_text(text, reply_markup=markup)
    except BadRequest as error:
        if "not modified" not in str(error).lower():
            raise


def _menu(context: ContextTypes.DEFAULT_TYPE) -> InlineKeyboardMarkup:
    """Обычное меню групп под сводкой с кнопками последней записи."""
    last = context.user_data.get(LAST_WRITE)
    return categories_menu(
        context.bot_data.get("categories", []),
        last is not None,
        premium_icons(context),
        check=len(last.get("checks", {})) if last else 0,
    )


def inline_check(
    context: ContextTypes.DEFAULT_TYPE,
) -> tuple[str, InlineKeyboardMarkup]:
    """Проверка единственной строки записи: текст и кнопки меню под сводкой."""
    last = context.user_data[LAST_WRITE]
    index = min(last["checks"])
    context.user_data[STATE] = {"write": _snapshot(last), "row": index, "mode": INLINE}
    categories = context.bot_data.get("categories", [])
    return check_text(last, index), check_keyboard(
        categories, premium_icons(context), INLINE
    )


def _queue_prompt(
    context: ContextTypes.DEFAULT_TYPE, state: dict, last: dict
) -> tuple[str, InlineKeyboardMarkup]:
    prefix = f"🔎 {state['done'] + 1} из {state['total']}. "
    categories = context.bot_data.get("categories", [])
    return check_text(last, state["row"], prefix), check_keyboard(
        categories, premium_icons(context), QUEUE
    )


async def start_check(
    reply: Callable[..., Awaitable[Message]], context: ContextTypes.DEFAULT_TYPE
) -> Message:
    """«🔎 Проверить»: строки с пометкой по одной, новым сообщением."""
    last = context.user_data.get(LAST_WRITE)
    pending = sorted(last.get("checks", {})) if last else []
    if not pending:
        context.user_data.pop(STATE, None)
        return await reply("Проверять нечего: все строки этой записи уже проверены.")
    state = {
        "write": _snapshot(last),
        "row": pending[0],
        "mode": QUEUE,
        "queue": pending,
        "done": 0,
        "fixed": 0,
        "total": len(pending),
    }
    context.user_data[STATE] = state
    text, markup = _queue_prompt(context, state, last)
    return await reply(text, reply_markup=markup)


async def start_fix(
    reply: Callable[..., Awaitable[Message]], context: ContextTypes.DEFAULT_TYPE
) -> Message:
    """Начало диалога /fix (команда или кнопка под сводкой); reply шлёт сообщение."""
    last = context.user_data.get(LAST_WRITE)
    if not last:
        return await reply(
            "Нечего исправлять: последней записи нет — она забывается после "
            "перезапуска бота, /undo и импорта выписки."
        )
    rows: list[SheetRow] = last["rows"]
    state = {"write": _snapshot(last)}
    context.user_data[STATE] = state
    if len(rows) == 1:
        state["row"] = 0
        return await reply(
            f"✏️ {describe(rows[0])}\nВыберите группу:",
            reply_markup=categories_keyboard(
                context.bot_data.get("categories", []), premium_icons(context)
            ),
        )
    listing = "\n".join(f"{i + 1}) {describe(row)}" for i, row in enumerate(rows))
    return await reply(
        f"✏️ Какую операцию исправить?\n{listing}", reply_markup=rows_keyboard(rows)
    )


async def fix_command(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    await start_fix(update.message.reply_text, context)


async def _inline_done(
    query: CallbackQuery, context: ContextTypes.DEFAULT_TYPE, text: str
) -> None:
    """Проверка в меню закончилась: под текстом снова обычное меню групп."""
    context.user_data.pop(STATE, None)
    source = context.user_data.get("source") or context.bot_data.get("last_source")
    prompt = category_prompt(source) if source else "Категория:"
    await _edit(query, f"{text}\n{prompt}", _menu(context))


async def _refresh_menu(context: ContextTypes.DEFAULT_TYPE) -> None:
    """После проверки по очереди кнопка «🔎 Проверить» в меню под сводкой обновляется."""
    last = context.user_data.get(LAST_WRITE)
    if not last or not last.get("menu"):
        return
    chat_id, message_id = last["menu"]
    try:
        await context.bot.edit_message_reply_markup(
            chat_id=chat_id, message_id=message_id, reply_markup=_menu(context)
        )
    except TelegramError as error:  # меню уже удалено или не изменилось
        logger.debug("Menu after the check was not updated: %s", error)


async def _checked(
    query: CallbackQuery,
    context: ContextTypes.DEFAULT_TYPE,
    state: dict,
    last: dict,
    verdict: str,
    fixed: bool,
) -> None:
    """Строка проверена: в меню — снова группы, в очереди — следующая строка."""
    last.get("checks", {}).pop(state["row"], None)
    if state["mode"] == INLINE:
        await _inline_done(query, context, verdict)
        return
    state["done"] += 1
    state["fixed"] += int(fixed)
    state["queue"] = [i for i in state["queue"] if i in last.get("checks", {})]
    state.pop("category", None)
    if state["queue"]:
        state["row"] = state["queue"][0]
        state["write"] = _snapshot(last)  # строки могли поменяться — новый снимок
        text, markup = _queue_prompt(context, state, last)
        await _edit(query, f"{verdict}\n\n{text}", markup)
        return
    context.user_data.pop(STATE, None)
    summary = f"✅ Проверено {state['done']}, исправлено {state['fixed']}."
    await _edit(query, f"{verdict}\n{summary}")
    await _refresh_menu(context)


async def _stop(
    query: CallbackQuery, context: ContextTypes.DEFAULT_TYPE, state: dict, text: str
) -> None:
    """Исправить не вышло: в меню — текст и снова группы, иначе — только текст."""
    if state.get("mode") == INLINE:
        await _inline_done(query, context, text)
        return
    context.user_data.pop(STATE, None)
    await _edit(query, text)


async def _cancel(query: CallbackQuery, context: ContextTypes.DEFAULT_TYPE) -> None:
    """«✖️ Отмена» и «⏹ Хватит»: в меню — снова группы, в очереди — итог."""
    state = context.user_data.get(STATE) or {}
    last = context.user_data.get(LAST_WRITE)
    current = bool(last) and state.get("write") == _snapshot(last)
    if current and state.get("mode") == INLINE:
        await _inline_done(query, context, "Категорию оставил как есть.")
        return
    context.user_data.pop(STATE, None)
    if current and state.get("mode") == QUEUE:
        done, total = state["done"], state["total"]
        await _edit(query, f"Проверку остановил: проверено {done} из {total}.")
        await _refresh_menu(context)
        return
    await _edit(query, "Исправление отменено.")


async def fix_button(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    """Кнопки /fix и проверки: fix:r:<i> — операция, fix:c:<i> — группа,
    fix:s:<i> — подгруппа, fix:ok — «✓ Верно», fix:b — назад, fix:x — отмена."""
    query = update.callback_query
    _, step, *rest = (query.data or "").split(":")
    await query.answer()
    if step == "x":
        await _cancel(query, context)
        return
    last = context.user_data.get(LAST_WRITE)
    state = context.user_data.get(STATE)
    if not last or not state or state["write"] != _snapshot(last):
        context.user_data.pop(STATE, None)
        await _edit(query, STALE)
        return
    rows: list[SheetRow] = last["rows"]
    categories: list[str] = context.bot_data.get("categories", [])
    subcategories: dict[str, list[str]] = context.bot_data.get("subcategories", {})

    if step == "r":
        index = _index(rest, rows)
        if index is None:
            await _edit(query, STALE)
            return
        state["row"] = index
        await _edit(
            query,
            f"✏️ {describe(rows[index])}\nВыберите группу:",
            categories_keyboard(categories, premium_icons(context)),
        )
        return
    if "row" not in state:
        await _edit(query, STALE)
        return
    row = rows[state["row"]]
    if step == "ok":
        if "mode" not in state:
            await _edit(query, STALE)
            return
        await _checked(
            query, context, state, last, f"👍 Оставил: {describe(row)}", False
        )
        return
    if step == "b":
        state.pop("category", None)
        if state.get("mode") == INLINE:
            await _edit(
                query,
                check_text(last, state["row"]),
                check_keyboard(categories, premium_icons(context), INLINE),
            )
        elif state.get("mode") == QUEUE:
            await _edit(query, *_queue_prompt(context, state, last))
        else:
            await _edit(
                query,
                f"✏️ {describe(row)}\nВыберите группу:",
                categories_keyboard(categories, premium_icons(context)),
            )
        return
    if step == "c":
        index = _index(rest, categories)
        if index is None:
            await _edit(query, STALE)
            return
        category = state["category"] = categories[index]
        await _edit(
            query,
            f"✏️ {describe(row)}\n{category} — выберите подгруппу:",
            subcategories_keyboard(
                subcategories.get(category, []),
                context.bot_data.get("icons"),
                premium_icons(context),
            ),
        )
        return
    if step != "s" or "category" not in state:
        await _edit(query, STALE)
        return

    category = state["category"]
    names = subcategories.get(category, [])
    index = _index(rest, names)
    if index is None:
        await _edit(query, STALE)
        return
    number = last["first"] + state["row"]
    amount = amount_for(row, category)
    if amount is None:
        await _stop(
            query,
            context,
            state,
            "Это списание — в доходы его не перенести. Если на самом деле это "
            f"поступление, поправьте строку {number} в таблице или удалите "
            "запись: /undo",
        )
        return
    gs_service: GoogleSheetsService = context.bot_data["gs_service"]
    try:
        changed = await asyncio.to_thread(
            gs_service.recategorize_row, number, row, category, names[index], amount
        )
    except Exception as error:
        logger.exception("Recategorization failed")
        await _stop(
            query,
            context,
            state,
            f"❌ Не исправил: {user_message(error)}. /fix — ещё раз",
        )
        return
    if not changed:
        await _stop(
            query,
            context,
            state,
            f"Строка {number} уже изменена в таблице — поправьте её там.",
        )
        return
    fixed = dataclasses.replace(
        row, category=category, subcategory=names[index], amount=amount
    )
    rows[state["row"]] = fixed  # /undo и следующий /fix сверяют уже новую категорию
    if ai_service := context.bot_data.get("ai_service"):
        ai_service.forget_history()  # магазин сразу пойдёт в исправленную категорию
    mark_dirty(context.bot_data)  # доход стал тратой или наоборот — сверка списка
    logger.info("Row %s recategorized", number)
    verdict = f"✅ Исправил (строка {number}): {describe(fixed)}"
    if "mode" in state:
        await _checked(query, context, state, last, verdict, True)
        return
    last.get("checks", {}).pop(state["row"], None)  # исправленная строка проверена
    context.user_data.pop(STATE, None)
    await _edit(query, verdict)
```

```python
Кнопки стоят в сообщении с группами сразу под сводкой (клавиатура карт живёт на
```

```python
"""SMS знакомых видов в чате → строки fact без ИИ (спека разбора SMS правилами).

prepare разбирает текст, отбрасывает уже записанные SMS, берёт категории из
памяти по сумме и истории магазинов, у новых магазинов спрашивает ИИ одним
запросом. None — текст не узнан: его, как раньше, разбирает ИИ.
"""

import asyncio
import logging
from collections import Counter
from dataclasses import dataclass
from typing import Any

from telegram.constants import ReactionEmoji
from telegram.ext import ContextTypes

from app import config
from app.domain import (
    Catalog,
    MerchantBook,
    ParsedTransaction,
    SheetRow,
    Skipped,
    build_row,
    local_today,
)
from app.handlers import live
from app.handlers.common import input_fingerprint, seen_input
from app.sms import Sms, SmsBatch, parse_sms
from app.sms_rows import CHECK, NEW, AmountMemory, new_merchants, sms_rows

logger = logging.getLogger(__name__)

SUGGEST_SECONDS = 30  # подсказка ИИ для новых магазинов; дольше — пишем без неё
SHOWN_ROWS = 5  # сколько номеров строк показать в «Уже записано раньше»


@dataclass(frozen=True)
class PreparedSms:
    """Сообщение из SMS, готовое к save_rows."""

    rows: list[SheetRow]
    flags: list[str | None]  # 🆕, ❓ или None у каждой строки
    prints: list[str | None]  # отпечаток SMS каждой строки; у комиссии — None
    skipped: list[Skipped]  # карта не найдена, нет курса
    notes: list[str]  # «⏭ Пропустил…», «⏭ Уже записано раньше…»

    @property
    def quiet(self) -> bool:
        """В сообщении были только коды и повторы — это не ошибка."""
        return not self.rows and not self.skipped


async def prepare(
    context: ContextTypes.DEFAULT_TYPE, chat_id: int, message: Any, text: str
) -> PreparedSms | None:
    """Текст SMS → строки для save_rows; None — правила текст не узнали."""
    try:
        batch = parse_sms(text)
    except Exception:
        logger.exception("SMS rules failed")
        return None
    if batch is None:
        logger.info("SMS rules: not recognized, AI parses")
        return None
    await live.react(message, ReactionEmoji.EYES)
    try:
        return await _prepare(context, chat_id, message, batch)
    except Exception:
        logger.exception("SMS rules failed")
        return None


def _fresh(
    context: ContextTypes.DEFAULT_TYPE, operations: list[Sms]
) -> tuple[list[Sms], dict[Sms, str | None], list[int]]:
    """Новые SMS и их отпечатки; повтор внутри сообщения и записанные раньше — мимо."""
    fresh: list[Sms] = []
    prints: dict[Sms, str | None] = {}
    repeated: list[int] = []  # строки fact, где эти SMS уже записаны
    here: set[str | None] = set()
    for sms in operations:
        fingerprint = input_fingerprint(sms.text)
        if fingerprint in here:
            continue
        here.add(fingerprint)
        if entry := seen_input(context, fingerprint):
            repeated.append(entry["rows"][0])
            continue
        fresh.append(sms)
        prints[sms] = fingerprint
    return fresh, prints, repeated


def _notes(skipped: list[str], repeated: list[int]) -> list[str]:
    """«⏭ Пропустил: код подтверждения ×2» и «⏭ Уже записано раньше: …»."""
    notes: list[str] = []
    if skipped:
        parts = [
            f"{reason} ×{count}" if count > 1 else reason
            for reason, count in Counter(skipped).items()
        ]
        notes.append("⏭ Пропустил: " + ", ".join(parts))
    if repeated:
        numbers = sorted(set(repeated))
        shown = ", ".join(map(str, numbers[:SHOWN_ROWS]))
        if len(numbers) > SHOWN_ROWS:
            shown += "…"
        where = f"строка {shown}" if len(numbers) == 1 else f"строки {shown}"
        notes.append(f"⏭ Уже записано раньше: {len(repeated)} SMS ({where})")
    return notes


async def _suggestions(
    context: ContextTypes.DEFAULT_TYPE,
    chat_id: int,
    message: Any,
    names: list[str],
    catalog: Catalog,
) -> dict[str, tuple[str, str]]:
    """Категории новых магазинов одним запросом; ошибка или 30 секунд — без них."""
    ai = context.bot_data.get("ai_service")
    if not names or ai is None or not getattr(ai, "enabled", False):
        return {}
    try:
        async with live.thinking(context, chat_id, message.message_id):
            return await asyncio.wait_for(
                ai.categorize_merchants(names, catalog), SUGGEST_SECONDS
            )
    except Exception:
        logger.warning("SMS rules: no merchant suggestions", exc_info=True)
        return {}


async def _prepare(
    context: ContextTypes.DEFAULT_TYPE, chat_id: int, message: Any, batch: SmsBatch
) -> PreparedSms:
    fresh, prints, repeated = _fresh(context, batch.operations)
    catalog = Catalog(
        categories=context.bot_data.get("categories", []),
        subcategories=context.bot_data.get("subcategories", {}),
        sources=context.bot_data.get("sources", []),
    )
    ai = context.bot_data.get("ai_service")
    book, fact = MerchantBook([]), []
    if ai is not None:
        book, fact = await asyncio.to_thread(ai.merchant_history)
    rates = await asyncio.to_thread(context.bot_data["gs_service"].get_rates)
    today = local_today(config.ANALYTICS_TIMEZONE)
    memory = AmountMemory.from_sheet(fact, today)
    names = new_merchants(fresh, catalog.sources, book, memory)
    suggestions = await _suggestions(context, chat_id, message, names, catalog)
    planned, skipped = sms_rows(
        fresh, catalog.sources, book, memory, suggestions, rates
    )
    rows: list[SheetRow] = []
    flags: list[str | None] = []
    row_prints: list[str | None] = []
    for position in planned:
        parsed = ParsedTransaction.model_validate(position.item)
        built = build_row(parsed, catalog, rates, today, None)
        if isinstance(built, Skipped):
            skipped.append(built)
            continue
        rows.append(built)
        flags.append(position.flag)
        row_prints.append(prints.get(position.sms) if position.sms else None)
    logger.info(
        "SMS rules: %d SMS → %d rows (%d new, %d to check, %d skipped, %d repeated)",
        len(batch.operations),
        len(rows),
        flags.count(NEW),
        flags.count(CHECK),
        len(batch.skipped) + len(skipped),
        len(repeated),
    )
    return PreparedSms(
        rows, flags, row_prints, skipped, _notes(batch.skipped, repeated)
    )
```
