# Вкладка «План» в Mini App — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Третья вкладка Mini App «План»: правка плана текущего месяца с телефона — суммы статей с подсказками по истории, список поступлений и платежей, цель накоплений — с записью во вкладку месяца Google-таблицы и сообщением второму пользователю.

**Architecture:** `app/services/plan.py` читает вкладку месяца (статьи в A:M по паре «подкатегория + валюта», список и цель в блоке прогноза O:S по заголовкам), считает подсказки по листу fact и превращает правки в одну запись `values_batch_update`, проверив, что ячейки не поменялись после открытия. API: `GET /api/plan?month=YYYY-MM` и `POST /api/plan` (409 со свежим планом при конфликте). Фронтенд держит черновик правок в `App` и в `localStorage`, экран `PlanScreen` считает итог по черновику и сохраняет кнопкой Telegram.

**Tech Stack:** Python 3.12, python-telegram-bot 22.8, Starlette 1.7, Pydantic 2, gspread, pandas; React 19.3, TypeScript 6.0 (strict), Vite 8.3, Tailwind 4.3, Vitest 5.0, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-11-plan-tab-design.md`

Этот документ — **этап 1** спеки (раздел 14): план текущего месяца. Этапы 2–4 (следующий месяц, «+ статья», советник) дописываются в этот же файл перед началом каждого — по коду, который сложится после этапа 1.

## Global Constraints

- Репозиторий публичный: в коде, тестах и образцах только условные суммы и названия; никаких реальных сумм, имён и ID.
- Секреты не читаем и не вводим: `.env` не открываем.
- Python: type hints на всех сигнатурах, black + ruff; перед коммитом `ruff check . && black --check . && pytest -q` (venv проекта).
- Фронтенд: функциональные компоненты и хуки, TypeScript strict, без `any` и без `!`-утверждений, Tailwind; перед коммитом в `webapp/`: `npm run lint && npm test && npm run build`.
- Месяц плана — `YYYY-MM`; допустимы текущий и следующий месяц по `ANALYTICS_TIMEZONE`, иначе 422 с полем `month`.
- Статья — пара (подкатегория, валюта), ключ `«подкатегория|ВАЛЮТА»`; пара, встречающаяся во вкладке дважды, только для чтения (`editable: false`).
- План во вкладке — D со знаком минус (и у расходов, и у доходов); в API и на экране — положительный. `0 ≤ plan ≤ 10¹²`, до двух знаков после запятой.
- Строка списка: название 1–40 символов, день 1–31, сумма не 0 (знак: «+» поступление, «−» платёж), валюта из курсов system!H. Цель: `0 ≤ amount ≤ 10¹²`, валюта из курсов.
- Блок прогноза ищем по текстам заголовков (`LIST_HEADER`, `GOAL_LABEL`, `TABLE_HEADER` из `app/services/day_budget.py`), не по номерам строк.
- Ошибки API: 422 `validation` с полями `month`, `rows`, `events`, `goal`, `changes`; 409 `plan_changed` с телом `{"error", "plan", "conflicts"}`; 503 `sheets_unavailable`.
- Сохранение: одна запись `values_batch_update` (`RAW`); в процессе одно сохранение за раз (`bot_data["plan_lock"]`).
- Уведомление: всем из `ALLOWED_USER_IDS`, кроме автора; не больше 10 строк правок, дальше «… и ещё N»; имя — `first_name` из initData, иначе `bot.get_chat`, иначе без имени.
- Черновик в `localStorage` по ключу `plan-draft:<userId>:<YYYY-MM>`; доступ к `localStorage` всегда в `try/catch`.
- Коммиты — conventional commits, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; тело PR заканчивается `🤖 Generated with [Claude Code](https://claude.com/claude-code)`; мерж — `gh pr merge --merge --delete-branch`.

## Review Focus

1. **Строку вставили во вкладку руками, пока план открыт** — запись находит статью по паре и пишет в сдвинутую строку, а не по старому номеру (тест в Task 5).

```python
"""Вкладка «План»: план месяца из вкладки, подсказки, правки, запись."""

from typing import Any

from app.services.plan import Event, Goal, read_plan

HEADER = ["Статья", "Категория", "Подкатегория", "План", "Факт", "Дельта", "Валюта"]
EVENTS = [("Аванс", 15, 3_000_000, "UZS"), ("Квартплата", 18, -500, "USD")]


def article(
    kind: str, group: str, sub: str, plan: float, currency: str = "UZS"
) -> list[Any]:
    """Строка статьи: D — план со знаком минус, G — валюта."""
    return [kind, group, sub, -plan, 0, plan, currency]


def month_tab(
    articles: list[list[Any]],
    events: list[tuple[str, int, float, str]] = EVENTS,
    goal: tuple[float, str] | None = (0, "UZS"),
) -> list[list[Any]]:
    """Вкладка месяца: статьи слева (A:G), блок прогноза справа (O:R) в тех же строках.

    Заголовок списка — строка 11, восемь строк списка — 12–19, цель — 20, таблица
    дней — с 21, как во вкладках таблицы.
    """
    rows: list[list[Any]] = [HEADER, *articles]
    rows += [[] for _ in range(30 - len(rows))]
    rows = [list(row) + [""] * (19 - len(row)) for row in rows]
    rows[10][14:19] = [
        "Поступления (+) и крупные платежи (−)",
        "День",
        "Сумма",
        "Валюта",
        "В сумах",
    ]
    for k, (name, day, amount, currency) in enumerate(events):
        rows[11 + k][14:18] = [name, day, amount, currency]
    if goal is not None:
        rows[19][14:18] = ["🎯 Отложить за месяц (цель накоплений)", "", *goal]
    rows[20][14:18] = ["Дата", "План", "Факт", "Разница"]
    return rows


def test_articles_are_pairs_of_subcategory_and_currency() -> None:
    plan = read_plan(
        month_tab(

                article("Расходы", "🍔 ЕДА", "кофе", 1_500_000),

        ("кофе|USD", "spend", "🍔 ЕДА", 20, 3),
```

```python
"""Вкладка «План» Mini App: план месяца из вкладки, подсказки, правки.

Вкладка месяца: статьи в A:M (тип A, группа B, подкатегория C, план D со знаком
минус, валюта G), справа блок прогноза O:S — список «Поступления (+) и крупные
платежи (−)» и цель накоплений. Статья — пара (подкатегория, валюта): по ней
вкладка считает факт, по ней же находим строку, а не по номеру.
"""

from dataclasses import dataclass, replace
from typing import Any

from app.services.day_budget import COLUMN_O, GOAL_LABEL, LIST_HEADER, TABLE_HEADER

KINDS = {"Расходы": "spend", "Доходы": "income"}
MAX_EVENTS = 20  # строк списка; дальше — уже не список, а сломанная вкладка

EventCells = tuple[str | None, int | None, float | None, str | None]


def article_key(subcategory: str, currency: str) -> str:
    """«кофе|UZS» — ключ статьи в API и черновике."""
    return f"{subcategory}|{currency}"


def _text(value: Any) -> str:
    return "" if value is None else str(value).strip()


def _number(value: Any) -> float | None:
    if isinstance(value, int | float) and not isinstance(value, bool):
        return float(value)
    return None


@dataclass(frozen=True)
class Article:
    """Строка статьи: план положительный, в валюте строки; row — номер строки листа."""

    key: str
    kind: str  # spend | income
    group: str
    subcategory: str
    currency: str
    plan: float
    row: int
    editable: bool = True


@dataclass(frozen=True)
class Event:
    """Строка списка поступлений и платежей; у пустой name — None."""

    slot: int
    row: int
    name: str | None
    day: int | None
    amount: float | None
    currency: str | None

    def cells(self) -> EventCells:
        return self.name, self.day, self.amount, self.currency


@dataclass(frozen=True)
class Goal:
    row: int
    amount: float
    currency: str


@dataclass(frozen=True)
class MonthPlan:
    articles: tuple[Article, ...]
    events: tuple[Event, ...] | None  # None — во вкладке нет блока прогноза
    goal: Goal | None


def _articles(rows: list[list[Any]]) -> tuple[Article, ...]:
    found: list[Article] = []
    for number, row in enumerate(rows[1:], start=2):
        cells = list(row[:7]) + [""] * (7 - len(row[:7]))
        kind = KINDS.get(_text(cells[0]))
        group, sub = _text(cells[1]), _text(cells[2])
        if kind is None or not group or not sub:
            continue
        currency = _text(cells[6]).upper() or "UZS"
        plan = 0.0 - (_number(cells[3]) or 0.0)
        key = article_key(sub, currency)
        found.append(Article(key, kind, group, sub, currency, plan, number))
    counts: dict[str, int] = {}
    for article in found:
        counts[article.key] = counts.get(article.key, 0) + 1
    return tuple(
        replace(article, editable=False) if counts[article.key] > 1 else article
        for article in found
    )


def _block(row: list[Any]) -> list[Any]:
    """O:R строки: название, день, сумма, валюта."""
    cells = list(row[COLUMN_O : COLUMN_O + 4])
    return cells + [""] * (4 - len(cells))


def _forecast(
    rows: list[list[Any]],
) -> tuple[tuple[Event, ...] | None, Goal | None]:
    start = next(
        (
            index
            for index, row in enumerate(rows)
            if _text(_block(row)[0]).startswith(LIST_HEADER)
        ),
        None,
    )
    if start is None:
        return None, None
    events: list[Event] = []
    goal: Goal | None = None
    for index in range(start + 1, len(rows)):
        name, day, amount, currency = _block(rows[index])
        label = _text(name)
        if label == TABLE_HEADER or len(events) == MAX_EVENTS:
            break
        if GOAL_LABEL in label:
            code = _text(currency).upper() or "UZS"
            goal = Goal(index + 1, _number(amount) or 0.0, code)
            break
        number = _number(day)
        events.append(
            Event(
                slot=len(events),
                row=index + 1,
                name=label or None,
                day=None if number is None else int(number),
                amount=_number(amount),
                currency=_text(currency).upper() or None,
            )
        )
    return tuple(events), goal


def read_plan(rows: list[list[Any]]) -> MonthPlan:
    """Значения вкладки месяца (UNFORMATTED) → статьи, список и цель."""
    events, goal = _forecast(rows)
    return MonthPlan(_articles(rows), events, goal)
```

```python
def shift_month(first: date, months: int) -> date:
    """Первое число месяца на months вперёд (назад — с минусом)."""
    index = first.year * 12 + first.month - 1 + months
    return date(index // 12, index % 12 + 1, 1)


@dataclass(frozen=True)
class History:
    """Подсказки: среднее за три полных месяца, прошлый и текущий месяц."""

    average_months: tuple[date, ...]
    last_month: date
    current_month: date
    current_days: int
    sums: dict[str, tuple[float, float, float]]  # ключ → (среднее, прошлый, текущий)

    def of(self, key: str) -> tuple[float, float, float]:
        return self.sums.get(key, (0.0, 0.0, 0.0))


def article_history(frame: pd.DataFrame, today: date) -> History:
    """Суммы листа fact по паре (подкатегория, валюта) в валюте строки.

    Знак как во вкладке: трата и доход плюс, возврат минус. Месяцы считаются от
    сегодняшней даты, месяц без записей — ноль.
    """
    current = today.replace(day=1)
    months = tuple(shift_month(current, -back) for back in (3, 2, 1))
    window = frame[(frame["day"] >= months[0]) & (frame["day"] <= today)]
    by_key: dict[str, dict[date, float]] = {}
    if not window.empty:
        month = window["day"].map(lambda value: value.replace(day=1))
        totals = (
            window.assign(month=month)
            .groupby(["subcategory", "currency", "month"])["amount"]
            .sum()
        )
        for (sub, currency, first), amount in totals.items():
            by_key.setdefault(article_key(sub, currency), {})[first] = float(amount)
    sums = {
        key: (
            sum(values.get(first, 0.0) for first in months) / len(months),
            values.get(months[-1], 0.0),
            values.get(current, 0.0),
        )
        for key, values in by_key.items()
    }
    return History(months, months[-1], current, today.day, sums)
```

```python
class EventValue:

    key: str
    base: float  # план, который видел пользователь
    plan: float


@dataclass(frozen=True)
class EventChange:
    slot: int
    base: EventCells  # строка списка, которую видел пользователь
    value: EventValue | None  # None — очистить строку


@dataclass(frozen=True)

class PlanChanges:
    articles: tuple[ArticleChange, ...] = ()
    events: tuple[EventChange, ...] = ()
    goal: GoalChange | None = None

    def count(self) -> int:
        return len(self.articles) + len(self.events) + int(self.goal is not None)


def _same(left: float | None, right: float | None) -> bool:
    if left is None or right is None:
        return left is None and right is None
    return abs(left - right) < TOLERANCE


def unknown(
    plan: MonthPlan, changes: PlanChanges, currencies: Collection[str]
) -> set[str]:
    """Поля, которые во вкладке не найти или нельзя править (ответ 422)."""
    bad: set[str] = set()
    editable = {a.key for a in plan.articles if a.editable}
    keys = [change.key for change in changes.articles]
    if len(set(keys)) != len(keys) or any(key not in editable for key in keys):
        bad.add("rows")
    slots = {event.slot for event in plan.events or ()}
    chosen = [change.slot for change in changes.events]
    if len(set(chosen)) != len(chosen) or any(
        change.slot not in slots
        or (change.value is not None and change.value.currency not in currencies)
        for change in changes.events
    ):
        bad.add("events")
    if changes.goal is not None and (
        plan.goal is None or changes.goal.value[1] not in currencies
    ):
        bad.add("goal")
    return bad


def conflicts(plan: MonthPlan, changes: PlanChanges) -> list[str]:
    """Что поменялось во вкладке после открытия плана: ключи, «event:<n>», «goal»."""
    found: list[str] = []
    articles = {a.key: a for a in plan.articles}
    for change in changes.articles:
        if not _same(articles[change.key].plan, change.base):
            found.append(change.key)
    events = {e.slot: e for e in plan.events or ()}
    for change in changes.events:
        name, day, amount, currency = events[change.slot].cells()
        base_name, base_day, base_amount, base_currency = change.base
        if (name, day, currency) != (base_name, base_day, base_currency) or not _same(
            amount, base_amount
        ):
            found.append(f"event:{change.slot}")
    if changes.goal is not None and plan.goal is not None:
        amount, currency = changes.goal.base
        if currency != plan.goal.currency or not _same(plan.goal.amount, amount):
            found.append("goal")
    return found


def cell_updates(
    title: str, plan: MonthPlan, changes: PlanChanges
) -> list[dict[str, Any]]:
    """Диапазоны для values_batch_update (RAW): D статей, O:R списка, Q:R цели."""
    articles = {a.key: a for a in plan.articles}
    events = {e.slot: e for e in plan.events or ()}
    data: list[dict[str, Any]] = []
    for change in changes.articles:
        row = articles[change.key].row
        data.append({"range": f"'{title}'!D{row}", "values": [[0.0 - change.plan]]})
    for change in changes.events:
        row = events[change.slot].row
        value = change.value
        cells: list[Any] = (
            ["", "", "", ""]
            if value is None
            else [value.name, value.day, value.amount, value.currency]
        )
        data.append({"range": f"'{title}'!O{row}:R{row}", "values": [cells]})
    if changes.goal is not None and plan.goal is not None:
        amount, currency = changes.goal.value
        row = plan.goal.row
        data.append({"range": f"'{title}'!Q{row}:R{row}", "values": [[amount, currency]]})
    return data


def _filled(event: Event, value: EventValue | None) -> Event:
    if value is None:
        return replace(event, name=None, day=None, amount=None, currency=None)
    return replace(
        event,
        name=value.name,
        day=value.day,
        amount=value.amount,
        currency=value.currency,
    )


def applied(plan: MonthPlan, changes: PlanChanges) -> MonthPlan:
    """План после правок — для «Свободно» в уведомлении."""
    plans = {change.key: change.plan for change in changes.articles}
    values = {change.slot: change.value for change in changes.events}
    articles = tuple(replace(a, plan=plans.get(a.key, a.plan)) for a in plan.articles)
    events: tuple[Event, ...] | None = None
    if plan.events is not None:
        events = tuple(
            _filled(e, values[e.slot]) if e.slot in values else e for e in plan.events
        )
    goal = plan.goal
    if changes.goal is not None and goal is not None:
        amount, currency = changes.goal.value
        goal = replace(goal, amount=amount, currency=currency)
    return MonthPlan(articles, events, goal)


@dataclass(frozen=True)
class Totals:
    """Итог плана в сумах по курсам system (как колонки H–J вкладки)."""

    incomes: float  # строки списка со знаком «+»
    spend: float  # план статей «Расходы»
    goal: float
    income_rows: float  # план статей «Доходы» — для сравнения со списком

    @property
    def free(self) -> float:
        return self.incomes - self.spend - self.goal


def totals(plan: MonthPlan, rates: Rates) -> Totals:
    def uzs(amount: float, currency: str | None) -> float:
        return amount * rates.to_uzs.get(currency or "", 0.0)

    spend = sum(uzs(a.plan, a.currency) for a in plan.articles if a.kind == "spend")
    income_rows = sum(
        uzs(a.plan, a.currency) for a in plan.articles if a.kind == "income"
    )
    incomes = sum(
        uzs(e.amount, e.currency)
        for e in plan.events or ()
        if e.name and e.amount is not None and e.amount > 0
    )
    goal = uzs(plan.goal.amount, plan.goal.currency) if plan.goal else 0.0
    return Totals(incomes, spend, goal, income_rows)
```

```python
NOTE_LINES = 10  # дальше — «… и ещё N»


def _plain(value: float) -> str:
    """«1 500 000», «650,50»: копейки, только если они есть."""
    if float(value).is_integer():
        return money(value)
    return f"{value:,.2f}".replace(",", " ").replace(".", ",")


def _amount(value: float, currency: str) -> str:
    return _plain(value) if currency == "UZS" else f"{_plain(value)} {currency}"


def _event_text(cells: EventCells) -> str:
    name, day, amount, currency = cells
    if not name or day is None or amount is None or not currency:
        return "—"
    sign = "+" if amount > 0 else "−"
    return f"{day} · {name} {sign}{_amount(abs(amount), currency)}"


def change_note(
    plan: MonthPlan,
    changes: PlanChanges,
    rates: Rates,
    month: date,
    author: str | None,
    icons: dict[str, str],
) -> str:
    """Сообщение второму: кто менял, что было → стало и «Свободно» до и после."""
    articles = {a.key: a for a in plan.articles}
    lines: list[str] = []
    for change in changes.articles:
        article = articles[change.key]
        parts = (icons.get(article.subcategory, ""), article.subcategory)
        label = " ".join(part for part in parts if part)
        if article.currency != "UZS":
            label += f" {article.currency}"
        lines.append(f"{label}: {_plain(change.base)} → {_plain(change.plan)}")
    for change in changes.events:
        value = change.value
        after = (
            "удалено"
            if value is None
            else _event_text((value.name, value.day, value.amount, value.currency))
        )
        lines.append(f"📅 {_event_text(change.base)} → {after}")
    if changes.goal is not None:
        (was, was_code), (now, now_code) = changes.goal.base, changes.goal.value
        lines.append(f"🎯 Отложить: {_amount(was, was_code)} → {_amount(now, now_code)}")
    shown = lines[:NOTE_LINES]
    if len(lines) > NOTE_LINES:
        shown.append(f"… и ещё {len(lines) - NOTE_LINES}")
    name = MONTHS_RU[month.month - 1]
    head = (
        f"✏️ {author} — правки в плане на {name}:"
        if author
        else f"✏️ Правки в плане на {name}:"
    )
    before = totals(plan, rates).free
    after_free = totals(applied(plan, changes), rates).free
    return "\n".join([head, *shown, f"Свободно: {short(before)} → {short(after_free)}"])
```

```python
    """Вкладки в памяти: get_values, get_rates; write_cells меняет те же строки."""

    def __init__(
        self, tabs: dict[str, list[list[Any]]], fact: list[list[Any]] | None = None
    ) -> None:
        self.tabs = {name: [list(row) for row in rows] for name, rows in tabs.items()}
        self.tabs["fact"] = fact or [FACT_HEADER]
        self.writes: list[list[dict[str, Any]]] = []
        self.delay = 0.0  # пауза чтения: в тесте гонки оба чтения идут раньше записи

    def get_values(self, name: str) -> list[list[Any]]:
        time.sleep(self.delay)
        if name not in self.tabs:
            raise WorksheetNotFound(name)
        return [list(row) for row in self.tabs[name]]

    def get_rates(self) -> Rates:
        return Rates({"UZS": 1.0, "USD": 12_000.0, "RUB": 150.0})

        self.writes.append(data)
        for item in data:
```

```python
def plan_month(text: str | None, today: date) -> date | None:
    """«2026-10» → 01.10.2026, если это текущий или следующий месяц."""
    try:
        first = datetime.strptime(text or "", "%Y-%m").date()
    except ValueError:
        return None
    current = today.replace(day=1)
    return first if first in (current, shift_month(current, 1)) else None


def plan_out(
    first: date, today: date, loaded: LoadedPlan | None, icons: dict[str, str]
) -> PlanOut:
    """План месяца для экрана; без вкладки — только статус."""
    month, title = f"{first:%Y-%m}", month_title(first)
    if loaded is None:
        status = "no_month_tab" if first == today.replace(day=1) else "not_created"
        return PlanOut(month=month, title=title, status=status, today=today)
    history, plan = loaded.history, loaded.plan
    rows = []
    for article in plan.articles:
        average, last, current = history.of(article.key)
        rows.append(
            PlanArticleOut(
                key=article.key,
                kind=article.kind,
                group=article.group,
                subcategory=article.subcategory,
                icon=icons.get(article.subcategory, ""),
                currency=article.currency,
                plan=article.plan,
                average=average,
                last=last,
                current=current,
                editable=article.editable,
            )
        )
    events = None
    if plan.events is not None:
        events = [
            PlanEventOut(
                slot=e.slot, name=e.name, day=e.day, amount=e.amount, currency=e.currency
            )
            for e in plan.events
        ]
    goal = None
    if plan.goal is not None:
        goal = PlanGoalOut(amount=plan.goal.amount, currency=plan.goal.currency)
    return PlanOut(
        month=month,
        title=title,
        status="ok",
        today=today,
        rates=dict(loaded.rates.to_uzs),
        history=PlanHistoryOut(
            average=[f"{m:%Y-%m}" for m in history.average_months],
            last=f"{history.last_month:%Y-%m}",
            current=f"{history.current_month:%Y-%m}",
            current_days=history.current_days,
        ),
        rows=rows,
        events=events,
        goal=goal,
    )
```

```ts
/** 409 сохранения плана: свежий план и что поменялось после открытия. */
export function planConflict(error: unknown): PlanConflict | null {
  if (!(error instanceof ApiError) || error.code !== "plan_changed") return null;
  const body = error.body;
  if (
    typeof body !== "object" ||
    body === null ||
    !("plan" in body) ||
    !("conflicts" in body)
  ) {
    return null;
  }
  return {
    plan: body.plan as MonthPlan,
    conflicts: body.conflicts as string[],
  };
}
```

```ts
/** Черновик плана: правки поверх плана из таблицы, итог, запрос на сохранение. */

import type {
  EventValue,
  MonthPlan,
  PlanArticle,
  PlanEvent,
  PlanGoal,
  PlanSave,
} from "../api";
import { amountValue, apiAmount } from "../entry/amount";

const EPSILON = 0.005; // суммы сравниваем до копейки, как сервер
const STORAGE = "plan-draft";

/** Правка статьи: base — план, который видели при открытии; text — как на клавиатуре. */
export interface RowEdit {
  base: number;
  text: string;
}

/** Новое содержимое строки списка: сумма без знака, знак — «Поступление» или «Платёж». */
export interface EventDraft {
  name: string;
  day: number;
  income: boolean;
  text: string;
  currency: string;
}

export interface EventEdit {
  base: PlanEvent;
  value: EventDraft | null; // null — очистить строку
}

export interface GoalEdit {
  base: PlanGoal;
  text: string;
  currency: string;
}

export interface Draft {
  month: string;
  rows: Record<string, RowEdit>;
  events: Record<string, EventEdit>; // ключ — номер строки списка
  goal: GoalEdit | null;
}

export interface PlanTotals {
  incomes: number;
  spend: number;
  goal: number;
  incomeRows: number;
  free: number;
}

export function emptyDraft(month: string): Draft {
  return { month, rows: {}, events: {}, goal: null };
}

export function changeCount(draft: Draft): number {
  return (
    Object.keys(draft.rows).length +
    Object.keys(draft.events).length +
    (draft.goal ? 1 : 0)
  );
}

function close(left: number | null, right: number | null): boolean {
  if (left === null || right === null) return left === right;
  return Math.abs(left - right) < EPSILON;
}

function without<T>(record: Record<string, T>, key: string): Record<string, T> {
  return Object.fromEntries(
    Object.entries(record).filter(([name]) => name !== key),
  );
}

export function eventAmount(value: EventDraft): number {
  return (value.income ? 1 : -1) * amountValue(value.text);
}

function sameEvent(event: PlanEvent, value: EventDraft | null): boolean {
  if (value === null) return event.name === null;
  return (
    event.name === value.name &&
    event.day === value.day &&
    event.currency === value.currency &&
    close(event.amount, eventAmount(value))
  );
}

function sameCells(left: PlanEvent, right: PlanEvent): boolean {
  return (
    left.name === right.name &&
    left.day === right.day &&
    left.currency === right.currency &&
    close(left.amount, right.amount)
  );
}

/** Сумма статьи в черновике; правка, равная плану, убирается. */
export function editRow(draft: Draft, article: PlanArticle, text: string): Draft {
  const base = draft.rows[article.key]?.base ?? article.plan;
  const rows = close(amountValue(text), base)
    ? without(draft.rows, article.key)
    : { ...draft.rows, [article.key]: { base, text } };
  return { ...draft, rows };
}

/** Строка списка в черновике; event — строка из плана, а не из черновика. */
export function editEvent(
  draft: Draft,
  event: PlanEvent,
  value: EventDraft | null,
): Draft {
  const key = String(event.slot);
  const base = draft.events[key]?.base ?? event;
  const events = sameEvent(base, value)
    ? without(draft.events, key)
    : { ...draft.events, [key]: { base, value } };
  return { ...draft, events };
}

export function editGoal(
  draft: Draft,
  goal: PlanGoal,
  text: string,
  currency: string,
): Draft {
  const base = draft.goal?.base ?? goal;
  const same =
    currency === base.currency && close(amountValue(text), base.amount);
  return { ...draft, goal: same ? null : { base, text, currency } };
}

export function rowPlan(draft: Draft, article: PlanArticle): number {
  const edit = draft.rows[article.key];
  return edit ? amountValue(edit.text) : article.plan;
}

export function shownEvents(plan: MonthPlan, draft: Draft): PlanEvent[] {
  return (plan.events ?? []).map((event) => {
    const edit = draft.events[String(event.slot)];
    if (!edit) return event;
    if (edit.value === null) {
      return {
        slot: event.slot,
        name: null,
        day: null,
        amount: null,
        currency: null,
      };
    }
    return {
      slot: event.slot,
      name: edit.value.name,
      day: edit.value.day,
      amount: eventAmount(edit.value),
      currency: edit.value.currency,
    };
  });
}

export function shownGoal(plan: MonthPlan, draft: Draft): PlanGoal | null {
  if (!plan.goal) return null;
  return draft.goal
    ? { amount: amountValue(draft.goal.text), currency: draft.goal.currency }
    : plan.goal;
}

/** Итог по черновику в сумах — как у сервера: поступления − расходы − цель. */
export function planTotals(plan: MonthPlan, draft: Draft): PlanTotals {
  const uzs = (amount: number, currency: string | null): number =>
    amount * (plan.rates[currency ?? ""] ?? 0);
  let spend = 0;
  let incomeRows = 0;
  for (const row of plan.rows) {
    const value = uzs(rowPlan(draft, row), row.currency);
    if (row.kind === "spend") spend += value;
    else incomeRows += value;
  }
  let incomes = 0;
  for (const event of shownEvents(plan, draft)) {
    if (event.name && event.amount !== null && event.amount > 0) {
      incomes += uzs(event.amount, event.currency);
    }
  }
  const shown = shownGoal(plan, draft);
  const goal = shown ? uzs(shown.amount, shown.currency) : 0;
  return { incomes, spend, goal, incomeRows, free: incomes - spend - goal };
}

function eventValue(value: EventDraft): EventValue {
  return {
    name: value.name,
    day: value.day,
    amount: `${value.income ? "" : "-"}${apiAmount(value.text)}`,
    currency: value.currency,
  };
}

export function toSave(draft: Draft): PlanSave {
  return {
    month: draft.month,
    rows: Object.entries(draft.rows).map(([key, edit]) => ({
      key,
      base: edit.base,
      plan: apiAmount(edit.text || "0"),
    })),
    events: Object.values(draft.events).map((edit) => ({
      slot: edit.base.slot,
      base: {
        name: edit.base.name,
        day: edit.base.day,
        amount: edit.base.amount,
        currency: edit.base.currency,
      },
      value: edit.value ? eventValue(edit.value) : null,
    })),
    goal: draft.goal
      ? {
          base: draft.goal.base,
          value: {
            amount: apiAmount(draft.goal.text || "0"),
            currency: draft.goal.currency,
          },
        }
      : null,
  };
}

/** Черновик поверх свежего плана: правки остаются, база — новые значения.
 * conflicts — где значение в таблице поменялось после начала правок. */
export function rebase(
  draft: Draft,
  fresh: MonthPlan,
): { draft: Draft; conflicts: string[] } {
  const conflicts: string[] = [];
  let next = emptyDraft(draft.month);
  for (const [key, edit] of Object.entries(draft.rows)) {
    const article = fresh.rows.find((row) => row.key === key && row.editable);
    if (!article) continue;
    if (!close(article.plan, edit.base)) conflicts.push(key);
    next = editRow(next, article, edit.text);
  }
  for (const [key, edit] of Object.entries(draft.events)) {
    const event = (fresh.events ?? []).find((item) => String(item.slot) === key);
    if (!event) continue;
    if (!sameCells(event, edit.base)) conflicts.push(`event:${key}`);
    next = editEvent(next, event, edit.value);
  }
  if (draft.goal && fresh.goal) {
    const { base } = draft.goal;
    if (
      base.currency !== fresh.goal.currency ||
      !close(base.amount, fresh.goal.amount)
    ) {
      conflicts.push("goal");
    }
    next = editGoal(next, fresh.goal, draft.goal.text, draft.goal.currency);
  }
  return { draft: next, conflicts };
}

/** Сумма для клавиатуры: копейки только у валюты; 0 — пусто. */
export function amountText(value: number, decimals: boolean): string {
  if (value <= 0) return "";
  if (!decimals) return String(Math.round(value));
  return value
    .toFixed(2)
    .replace(/\.?0+$/, "")
    .replace(".", ",");
}

function storageKey(userId: number, month: string): string {
  return `${STORAGE}:${userId}:${month}`;
}

function isDraft(value: unknown, month: string): value is Draft {
  return (
    typeof value === "object" &&
    value !== null &&
    "month" in value &&
    value.month === month &&
    "rows" in value &&
    typeof value.rows === "object" &&
    value.rows !== null &&
    "events" in value &&
    typeof value.events === "object" &&
    value.events !== null &&
    "goal" in value
  );
}

export function loadDraft(userId: number, month: string): Draft | null {
  try {
    const text = localStorage.getItem(storageKey(userId, month));
    if (!text) return null;
    const value: unknown = JSON.parse(text);
    return isDraft(value, month) && changeCount(value) > 0 ? value : null;
  } catch {
    return null;
  }
}

export function storeDraft(userId: number, draft: Draft): void {
  try {
    const key = storageKey(userId, draft.month);
    if (changeCount(draft) === 0) localStorage.removeItem(key);
    else localStorage.setItem(key, JSON.stringify(draft));
  } catch {
    // память недоступна (приватный режим): черновик живёт до закрытия приложения
  }
}
```

```tsx
  const [conflicts, setConflicts] = useState<string[]>([]);
  const draftRef = useRef(draft);
  const onDraftRef = useRef(onDraft);
  const inFlight = useRef(false); // второй тап до перерисовки не шлёт второй запрос
  const tg = telegram();

    draftRef.current = draft;
    onDraftRef.current = onDraft;
  });

  useEffect(() => {
    let alive = true;
    api.plan(month).then(
      (data) => {
        if (!alive) return;
        setPlan(data);
        setError(null);
        if (data.status !== "ok") return;
        // черновик с прошлого раза ложится на свежий план; что поменялось — подсветить
        const next = rebase(draftRef.current, data);
        setConflicts(next.conflicts);
        onDraftRef.current(next.draft);
      },
      (reason: unknown) => {
        if (!alive) return;
        setError(
          reason instanceof ApiError
            ? reason.message
            : "Не получилось загрузить план — попробуйте ещё раз",
        );
      },
    );
    return () => {
      alive = false;
    };
  }, [api, month, version]);

  const count = changeCount(draft);
  const label = `Сохранить ${changesText(count)}`;

  const save = useCallback(() => {
    if (inFlight.current || changeCount(draft) === 0) return;
    inFlight.current = true;
    setSaving(true);
    setNotice(null);
    api
      .savePlan(toSave(draft))
      .then(
        (fresh) => {
          haptic("success");
          setPlan(fresh);
          setConflicts([]);
          onDraft(emptyDraft(draft.month));
          setNotice(
            `✅ План сохранён: ${changesText(fresh.saved ?? changeCount(draft))}`,
          );
        },
        (reason: unknown) => {
          haptic("error");
          const conflict = planConflict(reason);
          const message =
            reason instanceof ApiError
              ? reason.message
              : "Не получилось сохранить";
          if (conflict) {
            const next = rebase(draft, conflict.plan);
            setPlan(conflict.plan);
            setConflicts(conflict.conflicts);
            onDraft(next.draft);
            setNotice(message);
            return;
          }
          setNotice(`${message}. ${KEPT}`);
        },
      )
      .finally(() => {
        inFlight.current = false;
        setSaving(false);
      });
  }, [api, draft, onDraft]);

  // Системная кнопка Telegram: «Сохранить N изменений», пока не открыто окно правки
  useEffect(() => {
    if (!tg || count === 0 || editing) return;
    tg.MainButton.setText(label);
    tg.MainButton.show();
    tg.MainButton.onClick(save);
    if (saving) tg.MainButton.showProgress(false);
    else tg.MainButton.hideProgress();
    return () => {
      tg.MainButton.offClick(save);
      tg.MainButton.hide();
    };
  }, [tg, count, editing, label, save, saving]);

  // «Назад» Telegram закрывает окно правки
  useEffect(() => {
    if (!tg || !editing) return;
    const close = () => setEditing(null);
    tg.BackButton.show();
    tg.BackButton.onClick(close);
    return () => {
      tg.BackButton.offClick(close);
      tg.BackButton.hide();
    };

  if (!plan) {
    if (!error) return <p className="text-hint">Загрузка плана…</p>;
    return (
      <div className="flex flex-col items-start gap-2" role="alert">
        <p>{error}</p>
        <button
          type="button"
          className="text-link"
          onClick={() => {
            setError(null);
            setVersion((current) => current + 1);
          }}
        >
          Повторить
        </button>

  if (plan.status !== "ok") {

      <p className="rounded-2xl bg-section p-4 text-sm">
        Вкладки месяца ещё нет — бот создаёт её сам 1-го числа.
      </p>
    );
  }

  const totals = planTotals(plan, draft);
  const events = shownEvents(plan, draft);
  const goal = shownGoal(plan, draft);
  const history = plan.history;
  const hint = (row: PlanArticle) =>
    history
      ? `ср. ${short(row.average)} · ${monthShort(history.last)} ${short(row.last)}`
      : "";
  const spend = groupsOf(plan.rows.filter((row) => row.kind === "spend"));
  const income = plan.rows.filter((row) => row.kind === "income");
  const filled = events
    .filter((item) => item.name !== null)
    .sort((left, right) => (left.day ?? 0) - (right.day ?? 0));
  const empty = events.find((item) => item.name === null);
  const differs =
    Math.abs(totals.incomeRows - totals.incomes) >
    0.01 * Math.max(totals.incomes, 1);
  const article =
    editing?.kind === "article"
      ? plan.rows.find((row) => row.key === editing.key)
      : undefined;
  const event =
    editing?.kind === "event"
      ? events.find((item) => item.slot === editing.slot)
      : undefined;
  const close = () => setEditing(null);

      key={row.key}
      article={row}
      value={rowPlan(draft, row)}
      edited={draft.rows[row.key] !== undefined}
      conflict={conflicts.includes(row.key)}
      hint={hint(row)}
      onPick={() => setEditing({ kind: "article", key: row.key })}
    />
  );

  return (
    <div className="flex flex-col gap-4">
      {restored && count > 0 && (
        <div
          className="flex flex-col gap-2 rounded-2xl bg-section p-3 text-sm"
          role="status"
        >
          <p>Есть несохранённые правки с прошлого раза</p>
          <div className="flex gap-4">
            <button type="button" className="text-link" onClick={onRestoredSeen}>
              Продолжить
            </button>
            <button
              type="button"
              className="text-danger"
              onClick={() => {
                onDraft(emptyDraft(month));
                setConflicts([]);
                onRestoredSeen();
              }}
            >
              Сбросить
            </button>
          </div>
        </div>
      )}
      {notice && (
        <p className="rounded-2xl bg-section p-3 text-sm" role="status">
          {notice}
        </p>
      )}
      <section
        className="flex flex-col gap-1 rounded-2xl bg-section p-4 text-sm"
        aria-label="Итог месяца"
      >
        <Line label="Поступления" value={short(totals.incomes)} />
        <Line label="Расходы по плану" value={short(totals.spend)} />
        <Line label="🎯 Отложить" value={short(totals.goal)} />
        <div className="mt-2 flex items-baseline justify-between border-t border-black/10 pt-2">
          <span className="font-semibold">
            {totals.free >= 0 ? "Свободно" : "Не хватает"}
          </span>
          <span
            className={`text-2xl font-semibold ${totals.free >= 0 ? "text-ok" : "text-danger"}`}
          >
            {short(Math.abs(totals.free))}
          </span>
        </div>
      </section>
      {plan.events === null ? (
        <p className="text-sm text-hint">
          Списка поступлений во вкладке нет — его правят в таблице.

          <h3 className="mb-1 text-xs font-semibold text-hint uppercase">
            Поступления и платежи
          </h3>
          {filled.map((item) => {
            const conflict = conflicts.includes(`event:${item.slot}`);
            const edited = draft.events[String(item.slot)] !== undefined;

            return (

      {goal && (
        <button
          type="button"
          data-conflict={conflicts.includes("goal") || undefined}
          className={`flex items-center justify-between rounded-2xl bg-section p-3 text-left ${conflicts.includes("goal") ? "ring-2 ring-warn" : ""}`}

        </button>
      )}
      {!tg && count > 0 && (
        <button
          type="button"
          className="h-12 rounded-xl bg-button font-semibold text-button-text disabled:opacity-50"
          disabled={saving}
          onClick={save}
        >
          {label}
        </button>
      )}
      {article && (
        <ArticleSheet
          article={article}
          text={
            draft.rows[article.key]?.text ??
            amountText(article.plan, article.currency !== "UZS")
          }
          history={plan.history}
          onDone={(text) => {
            onDraft(editRow(draft, article, text));
            close();
          }}
          onClose={close}
        />
      )}

        <EventSheet
          event={event}
          currencies={currencies(plan)}

              plan.events?.find((item) => item.slot === event.slot) ?? event;
            onDraft(editEvent(draft, original, value));

          }}
          onClose={close}
        />
      )}
      {editing?.kind === "goal" && goal && plan.goal && (
        <GoalSheet
          goal={goal}
          currencies={currencies(plan)}

            if (plan.goal) onDraft(editGoal(draft, plan.goal, text, currency));
            close();
          }}
          onClose={close}
        />
      )}
    </div>
  );
}
```

```tsx
import { ApiError, type Api, type Bootstrap } from "./api";
import DashboardScreen from "./dashboard/DashboardScreen";
import EntryScreen from "./entry/EntryScreen";
import HomeScreenButton from "./HomeScreenButton";
import {
  changeCount,
  emptyDraft,
  loadDraft,
  storeDraft,
  type Draft,
} from "./plan/draft";
import PlanScreen from "./plan/PlanScreen";

type Tab = "entry" | "dashboard" | "plan";

const TABS: { name: Tab; title: string }[] = [
  { name: "entry", title: "Ввод" },
  { name: "dashboard", title: "Сводка" },
  { name: "plan", title: "План" },
];

function errorText(reason: unknown): string {
  return reason instanceof ApiError
    ? reason.message
    : "Не получилось загрузить — попробуйте ещё раз";
}

export default function App({ api }: { api: Api }) {
  const [boot, setBoot] = useState<Bootstrap | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [version, setVersion] = useState(0);
  const [tab, setTab] = useState<Tab>("entry");
  const [draft, setDraft] = useState<Draft | null>(null);
  const [restored, setRestored] = useState(false);
  const draftLoaded = useRef(false);
  const reload = useCallback(() => setVersion((current) => current + 1), []);

  useEffect(() => {
    let alive = true;
    api.bootstrap().then(
      (data) => {
        if (!alive) return;
        setBoot(data);
        setError(null);
        if (!draftLoaded.current) {

          setRestored(stored !== null);

            role="tab"

            className={`rounded-lg py-1.5 text-sm font-medium ${
              tab === name ? "bg-bg shadow-sm" : "text-hint"
            }`}
            onClick={() => setTab(name)}
          >
            {title}
            {name === "plan" && unsaved && (
              <span
                role="img"
                aria-label="есть несохранённые правки"
                className="ml-1 inline-block size-1.5 rounded-full bg-link align-middle"
              />
            )}
          </button>
        ))}
      </nav>
      {needsBoot && !boot && !error && <p className="text-hint">Загрузка…</p>}
      {needsBoot && !boot && error && (
        <div className="flex flex-col items-start gap-2" role="alert">
          <p>{error}</p>
          <button type="button" className="text-link" onClick={reload}>
            Повторить
          </button>
        </div>
      )}
      {tab === "entry" && boot && (
        <EntryScreen api={api} boot={boot} onCatalogChanged={reload} />
      )}
      {tab === "dashboard" && <DashboardScreen api={api} />}
      {tab === "dashboard" && boot && (

          month={draft.month}
          draft={draft}
          restored={restored}
          onDraft={updateDraft}
          onRestoredSeen={restoredSeen}
        />
      )}
    </main>
  );
}
```

```bash
## Что делает
- `GET /api/plan?month=YYYY-MM` — план месяца из вкладки: статьи по паре «подкатегория + валюта» с подсказками (среднее за три полных месяца, прошлый месяц, текущий на сегодня), список поступлений и платежей, цель, курсы.
```
